# EMBER — 잿빛 정원의 불씨

현재 앰버의 이동 거점 재미를 바로 플레이해 보는 HTML 게임. 8개의 방에서 점프, 주변 점화, 흡수, 불 내부 발사, 링 대시, 선택 불씨 사격과 마지막 추격전을 체험한다.

## 실행

`index.html`을 Chrome 또는 Edge로 열면 된다. 인터넷 연결·패키지 설치·빌드가 필요 없다. `assets`, `game.js`, `levels.js`, `style.css`를 같은 폴더 구조로 유지한다.

현재 작업 중 로컬 주소: http://127.0.0.1:8791/ . 로컬 서버가 종료돼도 파일을 직접 열어 플레이할 수 있다.

## 조작

| 입력 | 행동 |
|---|---|
| A/D | 수평 이동 |
| WASD | 불 발사·링 대시 방향 선택 |
| Space | 일반/공중 점프. 불 내부에서는 발사. 링에서는 대시 |
| Shift | 주변 점화와 짧은 링 정지 |
| 마우스 오른쪽 | 커서와 가까운, 범위 안의 켜진 횃불로 흡수 |
| 마우스 왼쪽 누르고 놓기 | 7번 방의 선택 불씨 사격. 오래 누르면 더 빠르게 발사 |
| R / Esc | 현재 방 재시작 / 일시정지 |

착지하거나 불에 들어가면 공중 점프·링 사용권을 회복한다. 흡수는 벽을 통과하지 않는다. 링은 플레이어만 정지시키며 추격자의 시간은 계속 흐른다. 마지막 방에서는 어둠이 점유한 불을 노릴 수 있으므로 예고 전에 떠나야 한다. 소리는 기본 꺼짐이며 하단 버튼으로 켤 수 있다.

## 콘텐츠와 아트

1. 작은 불꽃의 발걸음 — 점프와 공중 점프.
2. 첫 횃불 — 점화, 흡수, 방향 발사.
3. 공중에서 길 만들기 — 접근 위치를 고르는 점화.
4. 뒤로 가야 열리는 길 — 거점과 출발 방향 선택.
5. 닫힌 회랑 — 두 횃불을 켜 문 열기.
6. 한 번의 방향 전환 — 발사 후 링 대시.
7. 불꽃 릴레이 — 거점 연결과 선택 사격.
8. 마지막 회랑 — 공격 예고를 읽는 추격과 탈출.

`assets/ember-scene.png`: 생성한 예시 장면. 게임의 아트워크 버튼에서 확대 가능.

`assets/ember-atlas.png`: 생성한 투명 4×4 스프라이트 시트. 플레이어와 횃불을 실제 애니메이션으로 렌더링한다. 이미지 생성 프롬프트는 `ART-PROMPTS.md`에 기록했다.

## 기획·Unity와의 관계

20분 상세기획을 체험 가능한 작은 장으로 재구성한 브라우저 시제품이다. 20분 플레이시간을 검증한 완성 빌드는 아니다. Unity 코드·씬·기존 에셋은 이 작업에서 변경하지 않았다.

이 시제품은 픽셀 단위 이동, 0.42초 링 선택 창, 독립 우클릭 흡수, 직선 흡수 경로와 8방향 대시를 사용한다. 사격은 7번에서 일반 상태에도 사용할 수 있는 조작 비교안이며, Unity의 C→X 링 사격·자원 공유 계약과 다르다. 20분 본편 기획을 이 조작으로 확정한 것은 아니다.

## 개발·검증

의존성 없는 Canvas와 classic script. 물리 갱신은 초당 120회, 렌더는 requestAnimationFrame. 외부 이미지·폰트·CDN을 요청하지 않는다. 진행 해금만 localStorage에 저장하고 재시작 시 횃불·문·추격자·플레이어 상태를 함께 복원한다.

`?qa=1`은 수동 물리 테스트 모드이며 사용자 플레이에는 사용하지 않는다. 테스트 훅 `window.EmberDemo`는 상태 조회·방 로드·입력·스텝·위치 이동을 제공한다. QA의 위치 이동 검사는 실제 동선 완주와 구분한다. 테스트 기록은 `tests` 폴더를 참고한다.
