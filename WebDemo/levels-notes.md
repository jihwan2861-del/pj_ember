# WebDemo 방 배치 메모

8개 960×540 단일 화면 비교안이다. 수치는 Unity와 직접 대응하지 않는다. 플레이어·횃불 좌표는 중심, 플랫폼·위험물·출구·문은 좌상단 좌표다. 모든 방에 y=525 낙사 위험선이 있다.

1. **발걸음:** x=230~310의 80px 틈, x=530~640의 110px 틈. 낮은 단차에서 짧은/긴 점프를 비교하고 마지막 틈에서 이단점프를 시험한다. 아직 점화·흡수·대시 없음.
2. **첫 횃불:** 높이 65px/35px의 계단 → (485,325) 가까이 점화 → 흡수 → 우상향 발사 → x=650,y=280 출구대. 꺼진 불은 안전대 끝에서 125px 안에 들어온다. 직접 이단점프 우회는 허용한다.
3. **공중 점화:** 출발대 오른쪽에서 뛰어 (390,290)를 점화·흡수 → 우상향 발사 중 (610,190) 접근 → 점화·흡수 → 오른쪽 발사로 넓은 출구대 착지. 출발대에서는 첫 불이 점화 범위 밖이다.
4. **거점 선택:** 뒤쪽 (248,285)에서 우상향 발사 → 천장 위로 통과 → (626,200) 흡수 → 오른쪽 발사. 앞쪽 (445,323)에서 출구 불로의 직선 흡수는 y=260~288 천장에 막힌다. 천장 아래 회수대에서 재도전할 수 있다.
5. **횃불 문:** 왼쪽 불 (305,330) 점화 → 우상향 발사로 오른쪽 불 (650,235) 접근·점화 → 두 불이 모두 켜지면 x=826의 전 높이 문이 열린다. 안전 바닥이 있어서 점화 실패는 회복 가능하다. 이 방만 점화가 출구의 명시적인 필수 조건이다.
6. **링 대시:** (310,360)에서 위 발사 → 천장 가시에 닿기 전 y≈220에서 링 → 오른쪽 대시 → (530,235) 흡수 → 우상향 발사로 x=730,y=260 출구대. 처음부터 우상향 발사해 우회하는 숙련 경로도 허용한다.
7. **릴레이:** (300,350)→(550,285)→(750,220) 세 켜진 불을 발사·흡수로 연결한다. 첫 두 불 중심 간 거리는 약 258px로 직접 A 범위 밖이지만 조금 발사하면 접근 가능하다. (770,115)는 선택 사격 지름길이며 출구 조건과 연결하지 않는다. S는 이 방에서만 허용.
8. **추격:** (280,365)→(530,285)→(760,220)→오른쪽 출구. 첫 연결은 약 262px여서 발사 후 흡수해야 한다. 쉬운 회수 발판 2개를 남기고, 마지막 위쪽 가시는 무입력 위 발사보다 오른쪽 탈출을 유도한다. 새 능력이나 사격은 요구하지 않는다.

## 물리·범위 가설

- 일반 점프 최대 상승은 약 98px, 공중 점프까지 쓰면 약 196px다. 이는 연속시간 근사이며 실제 브라우저 물리에서 확인해야 한다.
- 흡수 반경은 250px이다. 출구대에 도달하기 전 일부 연결은 250px를 조금 넘겨 L 후 A로 연결하게 했고, 벽 뒤 A는 정상 선택으로 표시하면 안 된다.
- 모든 필수 횃불은 고체 안에 박히지 않았으며, 흡수 직선이 플랫폼을 관통하지 않는 경로가 하나 이상 있다. 점화에는 정확한 한 프레임을 요구하지 않는다.
- 6번의 위 발사는 천장 가시와 의도적으로 만난다. 안전한 링 발동 위치는 대략 y=215~245이고, 대시로 x=410 이상 이동한 뒤 다음 불을 선택한다.
- 8번 추격은 충분한 시작 여유·방향 잠금·회복 시간이 필요하다. Anchored의 몸 충돌이 꺼져도 거점 점유 공격 예고를 표시해야 한다.
- 전역 데이터 이름은 `window.EMBER_LEVELS`다. 이 파일은 방 정의만 담당한다. 문은 `requires`에 적힌 두 불이 켜진 경우에만 열려야 한다.

아직 실행 검증 전 배치다. 세로 발사 후 제어 복구와 대시 종료 속도가 달라지면 6번 동선을 먼저 검증하고 범위를 조절한다.
