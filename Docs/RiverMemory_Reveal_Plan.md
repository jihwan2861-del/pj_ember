# 강에 남은 과거 — VFX·Particle System·라이팅 제작 계획

2026-10-20. **계획 문서이며 코드·씬·애셋 적용은 아직 하지 않았다.**

## 연출 목표

사용자 최신 흐름:

1. 마른 나무·누런 풀·오염된 태양이 현실과 물속에 보인다.
2. 강을 바라보면 물속부터 푸른 나무·풀·정상 태양의 과거가 드러난다.
3. 빛과 입자가 번지며 현실에서도 잠시 아름다운 과거를 본다.
4. 물 밖은 메마른 현재로 돌아온다.

되찾고 싶은 세계를 실제 화면으로 경험하게 한다. 새로운 태양이 되고 싶다는 앰버의 목표와 연결하는 방향이다. 평지 확장/NPC 만남과 강을 보라는 대사는 별도 설계 후보이며 문구·배치가 확정된 것은 아니다. 태양 갈기에서 C로 떨어지는 오프닝도 현재 별도 구상이다.

**미정:** 마지막 물속 반사를 푸른 과거로 남길지, 현재로 되돌릴지. 두 종료 모드를 설정으로 분리하고 사용자 결정 전 한쪽을 최종 확정하지 않는다. 과거 유지안은 NPC가 강을 안내하는 의미를 남기는 장점이 있다.

## 1. 현재 기반과 변경 지점

- URP17.6 / VFX Graph17.6 / Renderer2D가 프로젝트에 있다.
- 기존 `StoryWater2D.shader`·`StoryWater.mat`: 현재 화면 반사, 과거 레이어 합성, 물결 왜곡.
- 기존 `SurfaceRipples.vfx`: 수면의 잔빛. 현재 보이는 결과를 먼저 캡처해 보존한다.
- 기존 WaterSurface2D는 푸른 과거→시듦·태양 오염 순서다. 새 연출에서는 현재→과거 발견 방향으로 진행시킨다.
- 현재 나레이션 이벤트와 StoryTutorialSceneTransition은 TreeWitherProgress1을 기다린다. 단순히 재생 방향만 뒤집으면 진행 대기나 조기 페이드가 생길 수 있어 새 완료 신호로 연결해야 한다.
- 건강한/마른 나무·낮은/중간 발판 짝은 이미 있다. 높은 발판과 강둑의 건강한 짝·정상 태양 등은 실제 참조와 정렬을 확인해 재사용 여부를 정한다.

## 2. 화면 타임라인 초안

관찰을 시작한 뒤 약10게임초. 최종 속도는 실제 Game View에서 조절한다. 초기 현재 풍경은 발동 전까지 유지한다.

| 시간 | 단계 | 반사·현실 | 효과 |
| --- | --- | --- | --- |
| 발동 전 | 현재 | 물 안팎 모두 메마른 현재 | 낮은 채도의 물, 성긴 수면 잔빛 |
| 0~2.5초 | 발견 | 반사 속 나무·풀·태양이 과거로 전환 | 관찰 지점에서 잔물결이 퍼지고 수면 잔빛이 증가 |
| 2.5~4초 | 번짐 | 과거가 수면에서 물 밖으로 확장 | 물가부터 부드러운 빛 띠가 오르고 꽃가루가 흩날림 |
| 4~7초 | 아름다운 잔상 | 물 안팎에 건강한 과거 | 따뜻한 국소광·부드러운 반짝임·느린 꽃가루, 읽을 수 있는 유지 시간 |
| 7~9초 | 현실 복귀 | 물 밖 나무·풀·태양이 현재로 전환 | 꽃가루 방출을 멈추고 남은 입자와 빛을 천천히 감쇠 |
| 9~10초 | 여운 | 메마른 현실이 안정 | 효과를 정리하고 조작·다음 진행을 반환 |

반사와 현실의 정상 태양은 각 레이어의 전환에 맞춰 등장시킨다. 위쪽 정상 태양은 잔상 동안만 보이고 현실 복귀 때 오염 태양으로 돌아간다. 건강한 나무/마른 나무·돌의 접점은 같은 위치를 유지한다.

## 3. 기술별 역할

### 수면 셰이더 — 반사의 내용과 흔들림

- 현재→푸른 과거의 전환과 정상/오염 태양 반사의 교체를 담당한다.
- 기존 좌표 보정·Parallax 이후 실행 순서·캐릭터 반사를 보존한다.
- 발견 때 수면 왜곡이 작게 퍼졌다가 잦아들게 한다. 그림을 읽기 어려울 정도의 큰 왜곡은 피한다.
- 현실 변화와 반사 변화를 서로 다른 진행값으로 제어한다. 화면 캡처 반사만 사용하면 물 밖 복귀와 동시에 물속 과거도 사라질 수 있으므로 기존 별도 PastReflectionSources 합성을 유지한다.

### VFX Graph — 넓은 수면의 잔빛

- 기존 SurfaceRipples를 기반으로 수면 반짝임과 넓게 퍼지는 미세 잔광을 제어한다.
- Memory Amount / Emission Strength / Reveal Origin 같은 노출값으로 타임라인에 연결한다. 이름은 구현 시 기존 그래프 구조와 맞춘다.
- 과거 발견 때 관찰 지점에서 양옆으로 번지고, 잔상 유지 때 작은 잔빛만 남긴다.
- 수면 위·아래 표시 영역을 제한하고 나무·플레이어·나레이션을 과하게 덮지 않는다.

### Particle System — 눈에 읽히는 꽃가루·잎·짧은 불씨

- 수면에서 느리게 떠오르는 연노랑/크림색 꽃가루.
- 푸른 나무 주변에만 적게 흩날리는 작은 잎 또는 꽃잎.
- 과거가 현실로 번지는 순간의 짧은 빛 조각.
- 손그림 점·짧은 펜획·꽃잎 모양을 사용해 기존 낙서풍에 맞춘다. 눈 파티클·현실적인 연기 느낌은 이 장면의 기본으로 삼지 않는다.
- 첫 조정 목표는 CPU 입자 전체 동시 생존 수 약100~200개 이내다. 이는 출발점이며 성능을 측정한 수치가 아니다. 잎/입자마다 Light를 추가하지 않는다.
- 방출 정지와 소멸을 분리해 현실 복귀 때 갑자기 꺼지지 않게 한다.

### 라이팅 — 따뜻함과 화면의 깊이

- 나무·물가의 작은 구역부터 은은한 황금빛이 번지게 한다.
- Light2D는 실제 Lit 재질을 쓰는 대상과 정렬 레이어를 먼저 확인해 적용한다. 프로젝트에는 Unlit 재질도 있어 조명 강도만 올리는 방식으로 모든 그림이 바뀌지는 않는다.
- 물·하늘 등 조명 반응이 없는 대상은 셰이더 색/밝기와 별도 부드러운 빛 오버레이로 맞춘다. 수면 반사의 밝기도 같은 연출 진행값에서 제어한다.
- Global Light를 크게 올려 종이 배경과 검정 펜선을 날리지 않는다. 화사함은 녹색/따뜻한 색·국소광·공기 입자로 만든다.
- Bloom은 낮은 강도로 잔빛과 빛 조각에만 읽히도록 검토한다. 적용 전 카메라의 후처리 상태와 기존 Volume을 확인한다.

## 4. 물 밖 과거 풍경과 필요한 애셋

건강한 풍경을 물 밖에도 표시할 별도 시각 레이어를 둔다. 기존 물속 전용 숨김 레이어를 그대로 메인 카메라에 노출하지 않는다.

- 마른/건강한 나무, 발판의 누런/푸른 풀, 정상/오염 태양을 같은 접점·크기·pivot으로 짝지어 교차 전환한다.
- 돌 바탕과 지형 충돌은 그대로 두고 풀·잎·꽃 등 변하는 부분만 표시하는 것이 우선이다.
- 화면의 실루엣이 바뀌는 나무는 기존 건강한 나무 그림을 재사용한다. 이중 윤곽이 오래 보이지 않도록 마스크/전환 구간을 조정한다.
- 수면에서 위로 번지는 부드러운 마스크를 먼저 만들고, 개별 나무 반응은 약간의 시차를 준다.
- 작은 꽃가루/잎 텍스처는 기존 애셋을 먼저 조사한다. 새 PNG가 필요하면 새 이미지3개마다 실적용 캡처/사용자 확인 규칙을 적용한다.
- 현재 사용자가 옮긴 오브젝트 Transform·삭제한 발판·Collider는 보존한다.

## 5. 진행 제어와 연결

제안 컴포넌트명 `RiverMemorySequence`는 아직 생성하지 않았다. 하나의 진행 소유자가 아래 값을 따로 제어한다.

1. 물속 과거 비율.
2. 물 밖 과거 비율/번짐 높이.
3. 반사 태양과 위쪽 태양 상태.
4. 빛·잔광·입자의 방출량/감쇠.
5. 카메라 관찰 구도와 조작 잠금.

기존 WaterSurface2D를 확장해 외부 연출이 값을 소유하는 동안 옛 자동 시듦 로직과 경쟁하지 않게 한다. 다른 물 프리팹의 기존 기본 동작은 보존한다.

관찰 지점 착지와 짧은 머무름을 우선 발동 후보로 잡는다. 최종 위치는 평지/NPC 동선과 강이 잘 보이는 구도를 정한 뒤 선택하며, 지금 좌표를 임의 변경하지 않는다. NPC 대화 완료 조건은 별도 선택 설정으로 두어 독립 씬 확인이 가능하게 한다.

물 밖 잔상을 반드시 보게 할 짧은 구간만 선택적으로 잠근다. 물리 시간을 전역으로 멈추지 않고, 일시정지·배속과 맞는 게임 시간으로 진행한다. 카메라는 기존 CelesteRoomCamera 연출 기능을 사용한다.

나레이션을 먼저 닫아도 새 시퀀스가 끝나기 전 TutorialScene으로 넘어가지 않게 한다. StoryTutorialSceneTransition의 시듦 진행값 의존을 새 '현실 복귀/연출 완료' 신호로 바꾼다. 완료 후 기존 페이드→TutorialScene/탄생 연출 연결을 유지한다.

취소·비활성화·사망·재시작 시 자신이 획득한 잠금과 카메라 소유권만 해제한다. 임시 건강한 현실 그림과 빛/입자를 정리하고 초기 현재 상태로 복원한다. 재발동 정책은 기존1회 연출을 기준으로 명시한다.

## 6. 제작 순서와 비교 지점

- [ ] 현재 물가 Game View와 참조·재질·정렬 레이어를 캡처/기록.
- [ ] 효과 없이 '현재 반사→과거 반사'만 전환하고 좌표·태양 중복 확인.
- [ ] 물 밖 마른/건강한 그림 전환과 현실 복귀 구현. 이 단계에서4단계 의미가 읽히는지 확인.
- [ ] Light2D/색·빛 오버레이를 추가하고 검정 선·종이 밝기 보존 확인.
- [ ] VFX Graph 수면 잔빛을 연결하고 반사·정렬·가림 확인.
- [ ] Particle System 꽃가루/잎과 소멸 여운 추가.
- [ ] 카메라·선택 조작 잠금·나레이션/새 완료 이벤트와 다음 씬 연결.
- [ ] 현재/반사 발견/현실 잔상/현실 복귀의 같은 구도 실제 Play4장 캡처.
- [ ] 일시정지·배속·사망/재시작·중복 발동·취소와 기존 이동/충돌을 확인.
- [ ] 최종 물속 상태 결정 후 설정/태스크/인수인계 갱신.

완료 기준: 입자 없이도 과거/현재 변화가 읽히고, 효과를 더했을 때 낙서풍을 유지하며, 현실 복귀 후 숨은 건강한 그림·빛·잠금이 남지 않는다. 실제 화면과 확인한 범위만 완료로 기록한다.
