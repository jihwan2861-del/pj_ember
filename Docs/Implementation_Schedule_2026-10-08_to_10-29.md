기간: **2026년 10월 8일(목) 11:09 ~ 10월 29일(목) 11:09**, 한국 시간.

목표는 **튜토리얼 → 일반 방 14개 → 보스 방 1개 → 출구 승리**를 처음부터 끝까지 플레이할 수 있는 버전이다. 튜토리얼은 일반 방 14개와 별도로 잡는다. 방마다 고정된 역할을 붙이지 않고, 먼저 이동 경로를 만든 뒤 실제 플레이를 통해 기믹과 난이도를 조절한다.

## 작업 시간 가정

- 일반 작업일: 11:00~13:00 제작, 14:00~15:30 제작·연결, 15:30~16:00 플레이 테스트·기록·백업.
- 첫날 10/8: 11:09~13:00, 14:00~16:00.
- 일요일 10/11·10/18·10/25: 휴식 또는 밀린 필수 작업을 위한 예비일. 정규 작업량에 포함하지 않는다.
- 마지막 날 10/29: 09:00~11:09 최종 검수와 결과물 정리.
- 이 가정의 정규 작업량은 총 **74시간**이다. 실제 가능한 시간이 적으면 장식·추가 수집 경로부터 줄이고, 본편 완주와 오류 수정 시간을 유지한다.

## 현재 기반과 남은 작업

이미 있는 이동·점프·불 능력·밧줄·이동 발판·하강 발판·치킨 수집·물 접촉 소화·물의 정령 추적/파도/예고 돌진·Esc 일시정지·R 재시작 와이퍼를 재사용한다. 기존 기능을 다시 만드는 일정은 잡지 않는다.

파일 확인 기준으로 Player_no2의 네 애니메이션과 0/1/2/3 Blend Tree는 존재한다. PlayerAnimatorDriver는 공중에서 아직 Jump 값만 보내므로 Fall 분기를 연결해야 한다. 상승 물과 위쪽 추격 모드는 이번 계획의 새 구현으로 잡는다. 이전 개발 현황 문서에 남아 있는 5개 스테이지·별도 능력 계획은 이번 3주 범위에 추가하지 않는다.

2. 해당 구간에서 죽거나 R로 재시작해 초기화가 맞는지 확인한다.
3. 막히는 문제·헷갈리는 부분·필요한 수정 세 가지를 짧게 기록한다.
4. 씬과 프리팹을 저장하고 당일 변경을 로컬 커밋 또는 별도 백업으로 남긴다. 원격 업로드는 요청 시 진행한다.

## 보스전에서 지킬 설계

- HP를 깎는 전투가 아니라 **출구까지 도달하는 탈출전**으로 만든다.
- 정령은 Move로 추적한다. 별도의 파도 프리팹을 타지 않는다.
- 일반 파도는 위험 영역 표시 없이 발사하고 작은 화면 흔들림을 적용한다.
- 돌진은 위험 영역을 먼저 표시하며, 플레이어가 영역 밖에 있어도 예고한 방향으로 돌진한다.
- 공격 뒤 긴 회복 대기 없이 계속 추적하고 정령이 화면 밖으로 사라지지 않게 유지한다.
- 특정 조건에서 위쪽 추격 모드로 전환한다. 올라오는 물이 위로 이동할 이유를 만든다.
- 상승 물과 파도가 불타는 물체를 끄도록 기존 WaterContact를 재사용한다.
- 파도 크기는 실제 이단 점프 도달 높이를 확인한 뒤 회피 가능한 값으로 조절한다. 세 위험을 무조건 동시에 발생시키지 않고, 플레이 테스트 결과로 간격을 정한다.

## 일정이 밀릴 때

우선 줄일 것: 배경 장식, 추가 치킨 경로, 새 애니메이션, 추가 효과음과 새로운 기믹.

유지할 것: 일반 방 14개와 보스 방 1개의 필수 경로, 상승 물, 기존 파도·돌진, 출구 승리, 체크포인트, Esc/R, 최종 빌드와 오류 수정. 10/22 이후에는 진행을 막는 문제와 필수 기능 미완료만 우선 처리한다. 10/28을 새 기능 개발일로 사용하지 않는다.

## 마감 판정

- 실행 파일에서 튜토리얼부터 일반 방 14개와 보스 출구까지 완주할 수 있다.
- 사망은 체크포인트로 돌아가고, R은 와이퍼와 함께 씬 처음부터 재시작한다.
- Esc 정지/해제와 정지 중 R이 정상 동작한다.
- 상승 물·파도·돌진의 위험 판정과 초기화가 정상이며 출구 도착 후 공격이 중지된다.
- 치킨은 확정 전 사망 시 복귀하고, 수집 확정 후 사망 시 유지된다. R 씬 재시작 시 초기화된다.
- 심각한 컴파일 오류·진행 막힘·재시작 불능이 없고, 최종 결과물과 소스 백업이 남아 있다.

이 문서는 작업 계획이며 자동 실행 예약은 아니다. 하루 4시간이라는 가정을 바꾸면 작업량과 날짜를 함께 조정한다.
