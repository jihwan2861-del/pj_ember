# 일시정지와 재시작

FlamePlayerController가 있는 플레이어는 플레이 시작 시 GameSessionControls를 자동으로 추가한다. Player_no2에도 같은 이동 컨트롤러를 사용하면 자동 적용된다. 게임 씬이나 플레이어 프리팹에 별도 배치할 필요가 없다.

- Esc: 일시정지 / 해제.
- R: 현재 플레이어가 있는 씬을 처음부터 다시 불러온다. 일시정지 중에도 가능하다.
- 일시정지 화면의 Resume / Restart 버튼으로도 조작할 수 있다.

일시정지는 Time.timeScale을 0으로 설정한다. 플레이어와 능력 입력을 막고, 실시간으로 진행되던 사망 연출도 멈춘다. 조준 중에 일시정지하면 조준을 취소하고 슬로모션·물리 시간 간격을 복원한 뒤 정지한다. 해제 시 정지 전 시간 배율로 돌아온다.

R은 체크포인트로 돌아가는 사망 리스폰과 다르다. 씬에 배치된 초기 상태로 되돌리므로 현재 씬에서 수집한 치킨 등의 런타임 상태도 초기화한다. 기존 PrototypeRoom의 R 입력은 제거했고, 사망 시 방 리셋 API는 유지했다.

에디터에서는 저장된 씬을 직접 열어 플레이해도 재시작할 수 있다. 빌드에서는 해당 게임 씬이 Build Profiles의 Scene List에 포함되어 있어야 한다. 씬과 프로젝트 설정은 자동으로 수정하지 않는다.

## 재시작 와이퍼

R과 Restart 버튼은 사망 와이퍼와 같은 계단 모양으로 화면을 덮고, 완전히 덮인 상태에서 씬을 다시 불러온 뒤 화면을 연다. PlayerDeathEffect의 Wipe Out Duration, Wipe In Duration, Black Hold Duration, Wipe Steps를 함께 사용한다. 사망 파티클이나 사망 대기 시간은 재생하지 않는다. 전환 중에는 물리와 게임 입력을 멈추며 Esc/R 중복 입력도 무시한다. 와이퍼는 씬 전환 후 화면을 연 다음 제거된다.
