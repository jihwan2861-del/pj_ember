# 불꽃 조작 — 2026-10-21

- 방향키: 이동과 불씨·불 이동·탈출 방향 조준.
- Z: 점프/공중 점프. 불이나 로프 안에서는 조준 방향으로 탈출한다.
- X: 일반 상태에서 조준 방향에 불이 있으면 돌진·흡수한다. 유효한 불이 없으면 대시하며, 불 안에서는 다른 불로 이동한다.
- C: 주변 가연물을 폭발로 점화하고 짧은 점화 링 상태에 진입한다.
- 점화 링에서 Z: 방향키 조준 방향으로 대시. X: 현재 방향의 가연물에 점화·진입한다. 예전 X 누르기 조준/놓기 사격 입력은 제거했다.
- 태양꽃 불꽃은 X로 탑승한다. 꽃 발사 자체는 C 또는 다른 꽃 탄환 명중으로 활성화한다.
- 마우스: 사용하지 않는다.

이전 FlameShotAbility 컴포넌트와 직렬화 필드는 참조를 보존하기 위해 남아 있으나 플레이어 입력은 연결하지 않는다. 태양꽃 탄환은 FireFlower/FireFlowerProjectile의 별도 기능이다.

근처 제단과 상호작용할 수 있는 상태라면 C는 먼저 제단 상호작용을 시도한다.

Unity에서 실제 플레이와 타격감은 아직 확인하지 않았다.
