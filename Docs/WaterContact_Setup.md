# 물 접촉과 소화

물에 닿은 FlammableTile은 즉시 불이 꺼진다. 불 외형·이펙트·예약된 번짐도 중단한다. 물과 접촉하는 동안 수동 점화·불 투사체·주변 번짐으로 다시 켤 수 없다. 마지막 물에서 벗어나면 새 점화 요청을 받을 수 있으며 자동으로 켜지거나 젖음 시간이 추가되지는 않는다.

## 일반 물 배치

1. 물 오브젝트에 BoxCollider2D 등 실제 물 모양의 Collider2D를 붙인다.
2. 지형을 막지 않는 물이라면 Is Trigger를 켠다.
3. 같은 오브젝트에 `Ember Prototype > Water Contact`를 추가한다.
4. 불 오브젝트 또는 그 자식의 Collider2D가 물 안에 들어가면 불이 꺼지는지 확인한다.

정적인 물에도 별도 Rigidbody2D는 필요하지 않다. Water Contact는 같은 오브젝트의 활성 Collider2D들을 물 모양으로 사용한다. 여러 물이 겹치거나 대상에 콜라이더가 여러 개 있어도 마지막 실제 접촉이 끝날 때까지 점화를 막는다. 물·대상의 비활성화와 물 삭제도 접촉을 정리한다. 실행 중 물에 새로운 Collider2D를 추가했다면 Water Contact를 껐다 켜서 구성 목록을 갱신한다.

## 보스 파도

기존 WaterWave 프리팹에 Water Contact가 연결돼 있다. 실제 PolygonCollider2D를 사용하며 Play/Launch 시 활성화하고 Stop/Reset/비활성화 시 접촉을 해제한다. Deadly를 꺼도 소화는 적용된다. 빠른 파도는 물리 이동 구간도 조회하여 작은 불 오브젝트를 지나쳐도 소화한다.

보스 돌진 몸체와 위험 표시에는 물 판정을 추가하지 않는다. 기존 파도 피해와 정령 AI·애니메이션은 그대로 사용한다.

## 소화 API와 이벤트

`FlammableTile.Extinguish()`는 실제 불이 꺼졌을 때 true, 이미 꺼져 있으면 false를 반환한다. 초기 startsBurning 설정을 보존하고 FireStateChanged는 실제 소화 전환 때 알린다. onFireReset은 리스폰 초기화에만 호출하며 물 접촉으로 호출하지 않는다.

TryIgnite는 실제 물 접촉을 다시 확인한 뒤 점화를 허용한다. 따라서 물리 갱신 전 새로 물 안에 배치한 대상의 즉시 점화도 차단한다. IsWet은 마지막 접촉 동기화 상태다.

## 불 이용과 리스폰

꺼진 불은 흡수 미리보기·불 이동 대상으로 사용할 수 없다. 이동하던 목표 불이 꺼지면 기존 이동 중단 경로로 돌아온다. 일반 불 안에 있던 플레이어는 기존 안전 탈출 위치 조회를 사용해 자유 상태로 해제되며 추가 추진이나 사망 효과는 없다. 로프 끝이 꺼지면 기존 로프 이용 불가 해제 경로를 따른다. 불 상태를 구독하는 문은 현재 불 상태를 다시 평가한다.

MapReset은 이전 파도 접촉을 정리하고 초기 불 설정을 복원한 뒤 실제 물 접촉을 재동기화한다. 상시 물 안의 초기 불은 꺼진 상태를 유지한다. 사망 연출 동안 파도 재개 보류도 유지한다.

## 검증

Validation/WaterContact의 검증 스크립트는 별도 QA 프로젝트에서 새 물 접촉 검사와 기존 공격·이동·로프 회귀 검사를 실행한다. ValidationArtifacts/WaterContact에 로그·결과·소화 전후 화면을 저장한다. 본편 지형과 물 높이 연출은 자동 편집하지 않는다.
