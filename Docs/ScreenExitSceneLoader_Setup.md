# 화면 밖 이동 → story2 — 2026-10-18

## 최신 결정: 같은 Storyscene에서 진행

이하 story2 로드 설명은 이전 기록이다. 현재 Circle의 ScreenExitSceneLoader는 SceneFadeTransition.TryFade를 사용하며 씬을 로드하지 않는다.

- 오른쪽 화면 밖 이동 → 페이드아웃 → NextStoryStart로 플레이어 이동·NextCameraPose로 카메라 이동 → 페이드인.
- StoryContinuation/NextStoryStart와 NextCameraPose를 옮겨 다음 구간의 시작 구도를 조절한다. 초기 위치는 기존 평지 위 (16, -0.91), 카메라 (19, 0, -10)이다.
- 검은 화면 동안 종이 배경도 카메라 이동량만큼 옮긴다. 오염된 태양은 이후에도 화면 오른쪽 위를 따라간다.
- 새 시작점을 리스폰 지점으로 등록한다. 씬과 기존 진행 상태는 유지한다.
- On Continued는 검은 화면에서 위치 이동이 끝난 뒤 호출한다.
- story2는 빌드 씬 목록에서 제외했다. 기존 파일은 보존한다.
- 플레이 모드 전환 테스트는 수행하지 않았다.

- Storyscene의 Circle에 ScreenExitSceneLoader를 연결했다.
- 평지에서 플레이어 그림 전체가 카메라 오른쪽 끝을 벗어나면 검게 페이드아웃한다. 기본 여유는 화면 폭의 3%다.
- 원형 이동 중, 사망 중, 일시정지·재시작 전환 중에는 작동하지 않는다. 플레이어가 한 번 화면 안에 들어온 뒤에만 활성화된다.
- 페이드아웃 0.65초 → story2 비동기 로드 → 페이드인 0.4초. 시간은 인스펙터에서 수정한다.
- SceneFadeTransition의 오버레이는 씬 로드 동안 유지되며 완료 후 제거된다. 전환 동안 플레이어 조작과 일시정지/재시작을 차단한다.
- Storyscene과 Assets/Scenes/story2.unity를 빌드 씬 목록에 등록했다.
- story2는 사용자 요청으로 새로 만든 카메라만 있는 씬이다. 플레이어·지형·기믹 배치는 아직 없다. 기존 Storyscene은 계속 열어 두었다.
- 카메라가 나중에 플레이어를 계속 따라가도록 바뀌면 화면 밖 조건에 도달하지 않을 수 있다. 이 경우 출구 구간에서는 카메라가 멈추도록 경계를 잡거나 Trigger에서 SceneFadeTransition을 호출하는 연결이 필요하다.

플레이 모드 씬 전환 테스트는 수행하지 않았다.

## 2026-10-19 셀레스트 카메라 공존 수정
- ScreenExitSceneLoader가 활성화되면 CelesteRoomCamera의 자동 추적과 시작 스냅을 예약 방식으로 보류한다. 오프닝의 고정 구도를 유지해 오른쪽 화면 밖 이동 조건이 성립한다.
- 페이드 시작에 성공했을 때만 triggered를 기록한다. 목적지 연결이 빠졌으면 오류는 한 번만 알리고 인스펙터 수정을 기다린다.
- 암전 중 기존 시작점/카메라 포즈로 옮긴 뒤 OnContinued로 물가를 활성화한다. 새로 활성화된 룸을 갱신하고 오프닝 예약을 해제한다.
- 이후 StorySectionCamera는 플레이어가 유효한 CameraRoom 안에 있으면 CelesteRoomCamera에 제어를 넘긴다. 룸이 없는 구간은 기존 물가 추적/수면 높이 구도를 유지한다. 동시에 두 스크립트가 카메라 위치를 쓰지 않는다.
- 사용자가 만든 룸·지형·카메라 오프셋은 변경하지 않았다. 다음 구간도 룸 방식으로 제어하려면 해당 구간을 포함하는 CameraRoom을 사용자가 배치하면 된다.
- 컴포넌트를 껐다 켜도 전환 전 예약을 다시 확보한다. 셀레스트 카메라가 없는 씬은 기존대로 작동한다.
- 코드 재임포트와 직렬화 참조를 확인했다. 이번 수정 후 처음부터 진행하는 플레이 테스트는 실행하지 않았다.
