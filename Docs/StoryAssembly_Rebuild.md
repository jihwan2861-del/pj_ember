# Storyscene 조립 지도

작성 기준: 2026-10-21. 현재 구현된 기능을 새로 만들지 않고, 기존 씬 블록을 이야기 순서로 연결하기 위한 기준이다. 사용자가 고른 흐름은 **어두운 길 → 오염된 빛의 정령 구출 → 강가에서 과거 기억 → 시든 태양꽃에 에너지 전달 → TutorialScene**이다.

## 장면 구성

| 순서 | 재사용 블록 | 현재 위치/역할 | 연결 |
| --- | --- | --- | --- |
| 1 | `Opening_Comic` / `Circle`의 오프닝 컨트롤 | 만화 뒤 전역광을 끄고 플레이어 주변 빛으로 출발 | 만화 종료 → 걷기 시작 |
| 2 | `FlatGround` + `FlatGroundJoin` | 원형 회전을 진행하지 않고 기존 평지·경사를 따라 이동 | 강둑 시작점 `(34.1, 4.68)`에 접속 |
| 3 | `StoryShoreSection/Guide_NPC` | `(44.55, 1.05)`의 오염된 빛의 정령을 구하고 대화 | 정령 대화 종료 → 강가로 계속 걷기 |
| 4 | `StoryShoreSection`의 강가·발판·반사 | 기존 강가 배치를 그대로 재사용. `River`는 `(53.95, -2.3)`, 기억 카메라 초점은 `(66.5, -2.3)` | 가운데 발판 착지 → `RiverMemorySequence` |
| 5 | `StoryShoreSection/Withered Sunflower` | `(83, 0)`의 시든 태양꽃을 C로 깨우고 에너지 전달 | 에너지 연출 종료 → 기존 페이드 전환 |
| 6 | `TutorialScene` | X 점화/진입 → 꽃 불꽃 탑승 → C+Z 대시 교육 | 별도 교육 씬에서 계속 |

## 옮길 때 보존할 것

- 강가 루트는 `StoryShoreSection` 하나로 보존한다. 물, 충돌, 발판, 반사 원본, 나레이션·기억 이벤트, 건너편 꽃의 기존 참조를 새로 복사하지 않는다.
- `StorySectionCamera.sectionRoot`와 `RiverMemorySequence`의 발판·반사·광원 참조를 유지한다.
- `StoryShoreSection`의 월드 위치는 `(0, 0, 0)`이며, 강가 오브젝트는 이 루트 아래에 있다. 루트나 자식을 옮기면 배치·카메라 제한·착지 이벤트가 함께 바뀌므로, 현재 배치를 기준으로 연결한다.
- 튜토리얼은 현재 결정대로 `TutorialScene`에 둔다. Storyscene의 강가에서 장면을 끊거나 플레이어를 다른 위치로 워프하지 않는다. 기존 꽃 에너지 연출 뒤의 페이드/Single 로드만 사용한다.
- 원형 지형과 옛 연출 데이터는 삭제하지 않는다. 현재 오프닝 경로에서 쓰지 않는 데이터와 실제 진행 경로를 구분해 둔다.

## 현재 확인 범위와 다음 확인

현재 `Storyscene.unity` 직렬화에는 평지 진입, 정령, 강가 기억, 태양꽃, TutorialScene 전환 블록이 함께 있고 참조 대상 씬은 유지돼 있다. 이 문서는 배치 지도를 정리한 것이며, 새 Hierarchy 재부모화나 월드 좌표 이동을 수행한 기록은 아니다. Unity 편집기 화면을 사용할 수 없는 상태라 Game View에서 연속 진행·구도·착지를 캡처하지 못했다.

Unity에서 확인할 순서는 만화 뒤 어두운 길 → 정령 구출/대화 → 강가 진입 → 가운데 발판 기억 연출 → 시든 꽃 C 반응 → 페이드 후 TutorialScene이다. 캡처에서 강가 시작·중간 발판·꽃과 UI가 한 흐름으로 이어지는지 확인한 뒤 필요한 배치만 조정한다.
