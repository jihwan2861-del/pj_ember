# 파도 그림과 판정 조절

플레이를 끄고 `Assets/image/WaterWave` 프리팹을 열어 부모의 Water Wave 컴포넌트를 조절하세요. 기존 프리팹과 스프라이트 파일은 교체하지 않습니다.

## 그림

- **그림 바닥 자동 맞춤**: 켜 두세요. 중앙 피벗도 그림의 아래 중앙을 기준점에 맞춥니다. 피벗을 다시 편집할 필요가 없습니다. 투명 여백까지 포함한 스프라이트 사각형 기준이므로 남는 차이는 위치 조절로 맞추세요.
- **그림 위치 조절 X**: +는 오른쪽, -는 왼쪽입니다. 왼쪽 발사 때는 자동 반전됩니다.
- **그림 위치 조절 Y**: +는 위, -는 아래입니다. 0.1 정도씩 바꿔 보세요.
- **그림 크기 배율 X / Y**: 너비 / 높이입니다. 1은 기본, 0.8은 조금 작게, 1.2는 조금 크게입니다. 판정은 바뀌지 않습니다.
- **파도 그림 연결**: 자식 Wave Visual의 Sprite Renderer입니다. 그림이 하나라면 빈 칸도 자동 연결됩니다. 여러 그림이면 직접 지정하세요.

## 충돌 판정

부모의 Polygon Collider 2D → Edit Collider로 **오른쪽을 향한 원본 판정**을 편집하고 저장하세요. 인스펙터 변경이나 프리팹 재열기로 덮어쓰지 않습니다. 플레이 중 수정은 저장되지 않습니다.

게임 시작 시 저장된 판정을 복사해 사용합니다. 왼쪽 공격은 이 원본을 좌우 반전합니다. 반복 발사 때도 원본에서 반전하므로 반전이 누적되지 않습니다. AI가 공격 크기를 지정하면 원본 형태를 유지한 채 해당 기준 크기 변화만 비례 적용합니다.

하늘색 이동선과 끝 사각형은 경로/기준 크기 안내이며 실제 Polygon Collider 판정과 별개입니다. 판정의 실제 모양은 Edit Collider에서 확인하세요.

## 빠른 확인

1. Edit Collider에서 점 하나를 바꾸고 저장한 뒤 프리팹을 다시 열어 유지되는지 확인.
2. 그림 위치 Y를 0.2 바꾸고 그림만 이동하는지 확인.
3. 게임에서 좌우 발사 후 판정 방향 확인.
4. 이동 거리 끝에서 그림과 판정이 꺼지는지 확인.

프리팹 원본과 사용 중인 씬은 자동 저장/수정하지 않았습니다.
