# 플레이어 조작 효과음 연결

플레이어 프리팹 또는 씬의 플레이어에서 `Flame Player Controller > Player Action Sounds`를 펼칩니다.
각 항목의 `Clip`에 AudioClip을 드래그하고 `Volume`을 조절합니다. 비어 있는 슬롯은 소리가 나지 않으며 기술은 정상 작동합니다.

| 슬롯 | 재생 시점 |
| --- | --- |
| C Ignition Sound | C로 점화 링이 실제 시작될 때. 제단 상호작용은 제외 |
| C Z Dash Sound | X 독립 대시 또는 점화 링 안의 Z 대시가 실제 시작될 때 |
| X Absorb Sound | X로 불꽃 흡수 이동이 시작될 때. 불꽃 간 이동 포함 |
| X Z Launch Sound | 불꽃 또는 불타는 로프에서 Z로 실제 나올 때 |
| Z Jump Sound | Z로 일반 지상/공중 점프가 실제 시작될 때 |

`Action Audio Source`는 비워둬도 됩니다. 처음 설정된 소리를 재생할 때 플레이어 자식 `Player Action Audio`에 전용 2D AudioSource를 자동 생성합니다. 런타임에 생성되므로 편집 모드에는 보이지 않습니다.
믹서를 사용하려면 전용 AudioSource를 미리 만들어 슬롯에 연결하고, 해당 소스의 Output을 SFX 믹서 그룹에 연결하세요. Play On Awake와 Loop는 끄고 Spatial Blend는 0으로 설정합니다. 연결한 소스의 설정은 코드에서 변경하지 않습니다.

같은 파일을 여러 슬롯에 재사용할 수 있습니다. 실패한 입력에는 소리가 나지 않고, 버튼을 길게 누른다고 매 프레임 재생하지 않습니다. Z는 일반 상태에서 점프 입력이며, 발사/대시 상태에서는 점프 소리를 중복 재생하지 않습니다.

효과음 파일 선택, 불꽃 도착음, 불씨 발사음은 이번 연결에 포함하지 않았습니다. 프리팹 모드에서 설정하면 해당 프리팹을 사용하는 플레이어에 적용되며 씬 인스턴스에만 설정하면 그 인스턴스에만 적용됩니다.
