# 세계관과 기본 스테이지 방향 — 2026-10-14

태양이 힘을 잃으면서 세상에 물질인 오염이 퍼졌다. 작은 불꽃 정령은 불 기믹으로 오염을 제거하며 돌산을 올라 새로운 태양이 되려 한다.

기본 스테이지 완성이 보스전보다 우선이다. 본편은 일반 방 14개와 보스전 1개이며 방별 역할은 고정하지 않았다. 지형은 새로운 씬에서 제작한다.

핵심 흐름은 불 기믹 수행 → 오염 제거 → 길 개방 → 등반이다. 정화 대상과 조건은 기믹별로 결정하며 모든 불 능력이 모든 오염을 제거한다는 규칙은 없다.

오염은 검보라 덩어리·날카로운 가시·바위와 뿌리를 침식하는 줄기로 표현한다. 불과 정화는 주황·금빛으로 구분한다. 자연 가연물은 마른 풀·뿌리·고사목을 고려하며 현재 시안은 불붙는 뿌리다. 지형과 장애물 아트는 타일당 8×8픽셀을 기준으로 한다.

오프닝은 오염된 현재 지형에 오염이 없던 과거의 같은 장소가 겹쳐 보이는 연출이다. 따뜻했던 풍경을 본 정령은 “반드시 태양이 될 거야”라고 결심한다. 이 문서는 연출 방향을 기록하며 오프닝 구현 완료를 뜻하지 않는다.

첫 새 기믹은 불꽃꽃이다. C는 꽃을 활성화하고 꽃은 미리 정해진 방향으로 즉시 발사해 지정된 오염을 정화한다. 총알은 플레이어를 통과한다. 방향 변경 장치는 추후 검토한다.
