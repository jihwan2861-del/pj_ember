# 벽을 밀 때 공중 낙하가 느려지는 문제 수정

2026-10-05 / Unity 6000.5.3f1

## 재현과 원인

플레이어가 공중에서 수직 벽을 향해 방향키를 유지할 때 아래로 정상 낙하해야 한다. 기존에는 기본 물리 마찰이 벽을 미는 수평 힘에 반응해 수직 낙하를 늦췄다. 플레이어 프리팹과 지형에는 별도 PhysicsMaterial2D가 지정되지 않았다.

실제 FlamePlayerController와 네이티브 Physics2D를 0.02초씩 진행했다. 2씬의 이동·점프·중력·본체 Collider 설정, 기본 재질을 사용한 고체 벽에서 좌우 모두 재현했다. 30 tick(0.6초) 뒤 자유 낙하 거리는 5.127881 U였지만 오른쪽 벽을 밀면 3.491083 U, 왼쪽은 3.494600 U였다. 수직 속도도 자유 낙하 -16.73978 U/s에서 벽 접촉 -11.45978 U/s로 줄었다. 접지는 false이므로 잘못된 지면 판정은 이 재현의 원인이 아니다.

## 수정

FlamePlayerController가 Awake에서 본체 Collider에 마찰 0의 런타임 PhysicsMaterial2D를 적용한다. 기존 재질의 반발값은 유지한다. 이동 가속·제동, 중력과 수평 충돌은 기존 코드가 담당한다. 컴포넌트 파괴 시 원래 재질을 복원하고 생성한 재질을 해제한다.

씬·프리팹·패키지·프로젝트 설정은 변경하지 않았다. 변경 전 컨트롤러는 `Docs/AI/Backups/2026-10-05-wall-friction-before/FlamePlayerController.cs`에 보관했다. 방향키·Z/X/C 조작을 유지한다.

## 검증

같은 좌우 벽 재현에서 수정 후 낙하 거리와 속도는 자유 낙하와 동일했다(5.127881 U, -16.73978 U/s). 벽은 계속 수평 이동을 막았다.

격리 Unity 프로젝트에서 **29개 통과 / 실패 0 / 건너뜀 0**: 기존 입력·이동 17개, 발판 운반 10개, 새 벽 낙하 회귀 2개. 런타임 26개 소스를 그대로 복사해 컴파일했다. 지형 fixture가 필요한 별도 Tilemap 테스트는 이번 실행에서 제외했다.

결과: `ValidationArtifacts/MovementFeel/WallFriction/Before`와 `After`. 자동 EditMode 입력·물리 검증이며 실제 2씬 손 플레이, 렌더링, 실행 파일 빌드를 검증한 것은 아니다. 일반 바닥과 움직이는 발판 위의 제동·운반도 회귀 검증에 포함했다.
