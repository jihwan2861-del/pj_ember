# 2026-10-04 조작감 변경 전 재구성본

이 폴더는 이번 적용 직전 바이트를 미리 캡처한 백업이 아닙니다. 최초 파일 읽기와 이번에 적용한 정확한 패치를 기준으로 변경을 역변환한 재구성본입니다. 기존 사용자 변경을 포함하며 Git HEAD로 초기화한 파일이 아닙니다. 원래 읽힌 CRLF 줄바꿈으로 저장했습니다.

manifest.json에 각 원본 경로와 변경 전/변경 후 SHA-256을 기록했습니다. 되돌릴 때 해당 snapshot 파일을 source 경로로 복사하면 됩니다. .cs 복사본은 Unity가 중복 컴파일하지 않도록 Assets 밖에 보관합니다. 변경 후 코드를 추가로 수정했다면 현재 파일 전체를 덮어쓰기 전에 차이를 검토해야 합니다.

역변환 범위: 2 씬의 신규 이동 override 6개 제거, Driver의 이동속도 정규화 1곳 복원, Controller의 threshold 1/2 Motion 빈 슬롯 복원, JumpSetup의 빈 슬롯 복구/원본 Sprite 검증/기존 Motion 보호를 적용 전 코드로 복원.
