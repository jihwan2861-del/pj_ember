## 현재 조작의 출처

`Assets/EmberPrototype/Runtime/PlayerAbilityInputRouter.cs`와 `FlamePlayerController.cs`를 기준으로 실제 입력을 확인한다.

- 방향키: 좌우 이동과 능력 조준. 마우스 입력은 사용하지 않는다.
- 일반 상태 Z: 새로 눌렀을 때 점프·공중 점프.
- 일반 상태 X: 조준 방향에 유효한 불이 있으면 흡수 이동, 없으면 대시한다. 착지·불/로프 진입 시 대시가 충전된다.
- 일반 상태 C: 주변 가연물을 폭발로 점화해 짧은 링 상태에 진입한다. 근처 제단과 상호작용할 수 있으면 폭발보다 상호작용이 우선한다.
- 점화 링에서 Z는 방향키 방향 대시, X를 누르고 방향을 고른 뒤 놓으면 불씨를 발사한다. 점화 링은 C로 진입한다.
- 불/로프 내부 Z: 방향키로 조준한 방향 탈출·박차기. X: 조준한 다른 불로 이동. 대상이 없으면 머무른다. C 폭발은 불/로프 안에서 사용할 수 없다.

능력 해금과 상태에 따라 입력 조건이 있으므로 표기만 보고 모든 입력이 언제나 가능한 것으로 해석하지 않는다. **바람 버전의 X 글라이더·C 독립 대시는 현재 조작 계약이 아니다.**
