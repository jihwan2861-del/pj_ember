# 기본 스테이지 구현 계획

기준일: 2026-10-14. 기본 스테이지 완성이 보스전보다 우선이다.

## 목표와 확정 기준

태양이 쇠퇴하면서 물질인 오염이 퍼진 세계에서, 작은 불꽃 정령이 불 기믹으로 길을 열며 돌산을 올라 새로운 태양이 된다.

플레이 흐름은 **불 기믹 수행 → 오염 제거 → 길 개방 → 등반**이다. 본편은 일반 방 14개와 보스전 1개이며, 방별 역할과 기믹 배정은 아직 고정하지 않았다. 새로운 제작 씬의 지형을 기준으로 기믹을 배치한다.

조작은 방향키와 Z/X/C를 유지한다. C는 주변 점화 폭발이다. 가연물과 정화 대상은 구분하고, 오염 제거 조건은 기믹마다 정한다. 모든 불 능력으로 모든 오염을 제거하는 규칙을 도입하지 않는다.

## 1. 불꽃꽃 기믹 — 구현한 프로토타입

시든 꽃의 반응 범위에서 성공한 C 폭발에 반응한다. C는 활성화만 담당한다. 꽃마다 미리 설정한 방향으로 즉시 발사하며 플레이어 위치로 조준하지 않는다. 총알은 플레이어를 통과하고 사거리까지 진행한다. 방향 변경 장치는 추후 검토한다.

불꽃은 지정된 오염을 정화해 충돌과 위험 구역을 제거한다. 일반 벽에서는 멈추고 플레이어에게 닿으면 사망한다. 재시작하면 꽃·발사 준비·불꽃·오염 상태가 초기화된다.

- 코드: FireFlower, FireFlowerProjectile, PollutionObstacle.
- 연결: 기존 C 폭발과 MapReset.
- 확인 씬: Assets/EmberPrototype/FireFlowerValidation.unity.
- 검증: Unity 6000.5.2f1의 관련 검사 6개 통과. 실제 Play Mode의 C 반응과 정화까지 확인.
- 배치와 수치 설정: [FireFlower_Setup.md](../../FireFlower_Setup.md).
- 참고 이미지: [고정 조준 불꽃꽃](../../../ArtReference/FireFlower_FixedAim_Reference.png).

완성 아트와 본편 배치는 남아 있다. 테스트 씬은 동작 확인용이다.

## 2. 제작 지형에 기본 플레이 연결 — 다음 작업

사용자가 제작한 새 씬에서 이동·점프·불 이동·체크포인트·카메라 경계·출구를 연결한다. 먼저 짧은 구간에서 시작 → 불 기믹 → 정화 → 길 개방 → 다음 발판까지 이어지는 흐름을 완성한다.

불꽃꽃은 플레이어가 C 반응 범위를 읽고, 고정된 조준을 본 뒤 비켜날 공간이 있도록 배치한다. 발사 경로 뒤에 정화 대상 오염을 둔다. 실패 시 재시작하거나 꽃을 다시 활성화할 수 있도록 방별 재사용 조건을 결정한다.

확인 기준:
- 일반 이동으로 반응 범위와 회피 위치에 도달할 수 있다.
- 조준 예고를 보고 발사 전에 비켜날 수 있다.
- 정화 전에는 길이 막히고, 정화 후에는 다음 경로로 진행할 수 있다.
- 죽거나 재시작해도 기믹이 막힌 상태로 남지 않는다.

## 3. 오염과 자연 가연물의 역할 정리

오염은 검보라 덩어리·가시·침식하는 줄기로 표현한다. 정화 후 표현은 주황·금빛 식물이나 깨끗해진 지형이다. 각 오염 구역에 제거 조건, 위험 판정, 열린 뒤의 경로, 초기화 규칙을 지정한다.

횃불을 대신할 자연 가연물은 마른 풀·뿌리·고사목을 검토한다. 현재 시안의 불붙는 뿌리부터 기존 FlammableTile과 연결한다. 불 이동 거점인 가연물과 길을 막는 정화 대상 오염은 배치·아트·충돌 역할을 분리한다.

## 4. 8×8 타일 아트 적용

지형과 장애물은 타일당 8×8픽셀을 기준으로 제작한다. 꽃이나 정령 등 전체 스프라이트의 크기는 역할에 맞춰 별도로 정한다. Point 필터를 사용하고, 시각적 가시 끝과 실제 위험 콜라이더를 비교해 조정한다.

시든 꽃/활성 꽃, 점선 예고, 발사 불꽃, 오염 파괴, 정화 후 금빛 표현을 구별한다. 임시 사각형과 테스트 꽃 이미지를 최종 픽셀 애셋으로 교체한다.

## 5. 오프닝 — 연출 계획

오염된 현재 지형 위에 오염이 없던 과거의 같은 장소를 겹쳐 보여준다. 지형 위치는 일치시키고 과거의 따뜻한 색과 현재의 오염을 대비한다. 정령은 “반드시 태양이 될 거야”라고 결심한다.

과거 배경/현재 배경, 표시 트리거, 전환 시간, 대사 표시를 만든 뒤 첫 플레이 구간으로 연결한다. 현재 이 연출은 기획만 기록했으며 구현하지 않았다.

## 6. 본편 확장과 보스전

완성한 기본 흐름을 일반 방 14개로 확장한다. 각 방의 역할은 실제 지형과 플레이 확인 결과에 따라 정한다. 난이도·체크포인트 간격·회피 공간·정화 조건을 확인한 뒤 본편 진행을 연결한다.

물의 정령 보스와 기존 파도 코드는 보존한다. 기본 스테이지 흐름이 갖춰진 뒤 보스전 작업을 이어간다.
