# 불의 정령 작업 기준과 우선순위

최신 결정일: **2026-10-15**

현재는 **불의 정령 콘셉트**, 복원 기준은 `1b7a702`, 현재 Unity는 **6000.6.5f1**이다. [현재 인수인계](Docs/AI/FireProject_Handoff.md)를 먼저 읽는다.

## 확정한 기준

- 불 버전의 코드·씬·프리팹을 기준으로 이어간다.
- 본편은 일반 방 **14개 + 보스전 1개**다. 사용자가 타일 지형을 제작한다.
- 바람 단계에서 만든 글라이더·자동 기류·깃털 작업 목록은 현재 실행 목록이 아니다.
- 기본 스테이지 완성이 보스전보다 우선이다. 불꽃꽃 프로토타입 다음에는 사용자 제작 지형에 기본 플레이 흐름을 연결한다. 현재 작업 순서는 [문서 안내](Docs/README.md)와 최신 사용자 지시를 따른다. [이전 구현 계획](Docs/Archive/Design/StageImplementationPlan.md)은 과거 기록이다.

## 다음 작업 선택

2026-10-19 나레이션은 GamjaFlower 폰트와 Lines 편집, 타이핑·출력 완료 후2초 자동 진행, 인스턴스별 선택 잠금을 지원한다. 현재 물가의 잠금false를 유지했고 실제 입력·자동 종료·다중 문장·일시정지를 확인했다. [나레이션 설정](Docs/StorybookNarration_Setup.md)을 따른다.

2026-10-19 첫 게임 튜토리얼의 구현 범위·그레이박스 타일맵 편집 기준·확인한 X→Z 착지 진행은 [게임 튜토리얼 설정](Docs/GameTutorial_Setup.md)을 따른다. 세 번째 C→방향키+Z 교육은 기존 Level Workflow로 생성해 오른쪽에 연결했고, 실제 순차·동시 입력과 착지 완료·사망 재시도를 확인했다. [점화 대시 설정](Docs/IgnitionDash_Setup.md)을 따른다. 전체 오프닝 입력 완주와 별도 탄생 연출은 완료로 처리하지 않는다.

두 번째 꽃 구간은 C 발사→슬로→X 탑승→Z 하차→정화·착지 완료와 자동 하차2게임초/이후 직진1게임초를 확인했다. 분리 아트·프리팹·그레이박스 편집·확인 범위는 [대형 태양꽃 탑승 설정](Docs/FlowerRide_Setup.md)을 따른다.
