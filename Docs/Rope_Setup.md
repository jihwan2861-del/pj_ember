# 불붙은 로프 설정

## 테스트 씬

`Assets/EmberPrototype/RopeValidation.unity`를 열고 Play로 확인한다. 오른쪽 방향키와 X로 시작 불꽃에 들어간 뒤 오른쪽+Z로 발사한다. 다음 줄 끝을 향해 X로 들어가 좌우로 반동을 키우고, 오른쪽 위로 올라갈 때 Z로 나온다. 같은 조작으로 두 번째 줄에 들어가 오른쪽 착지 지점으로 이동한다. R은 처음 상태로 재시작한다.

씬을 새로 생성할 때는 `Ember Prototype > Create Rope Validation Scene` 메뉴를 사용한다. 기존 파일이 있으면 덮어쓰지 않으며 열려 있는 방이나 Build Settings를 변경하지 않는다. 아직 저장하지 않은 새 씬을 열어두었다면 먼저 저장한 뒤 실행한다. 이 씬은 조작 검증용 단순 도형이며 최종 레벨 아트는 아니다.

로프는 고정점 오브젝트의 `BurningRope`와 자식 끝 오브젝트의 `FlammableTile`로 구성한다. 끝에는 작은 Trigger `CircleCollider2D`를 붙이고 부모의 End Fire에 연결한다. 끝의 Absorb Point는 비워 끝 중심을 사용한다. 몸통에는 가연물 컴포넌트를 붙이지 않는다. 고정점은 이동하지 않는 위치에 배치하며 Transform Scale은 (1,1,1)을 사용한다.

Length는 기본 3, Initial Angle은 아래쪽을 0도로 보는 시작 각도다. Initial Angular Speed는 초당 도 단위이며 기본 0으로 정지 시작한다. 시작부터 불붙게 하려면 끝의 Starts Burning을 켠다. 줄 색은 점화 상태를 따르고 끝은 기존 불꽃 효과를 사용할 수 있다. 플레이 중 줄 끝 위치는 자동 계산되므로 끝의 Transform을 따로 움직이지 않는다.

몸통은 지형과 충돌하지 않으므로 스윙할 공간을 확보한다. 플레이어 크기를 고려해 바닥과 벽에서 떨어뜨린다. 로프 중간은 X 진입 대상이 아니며 끝의 불꽃만 기존 대상 선택 범위에 들어간다.

## 기본 스윙 값

| 항목 | 초기값 | 의미 |
|---|---:|---|
| Gravity | 18 | 진자 중력 |
| Input Acceleration | 14 | 좌우 입력의 힘 |
| Damping | 0.08 | 스윙 감쇠 |
| Maximum End Speed | 24 | 줄 끝 속도 상한 |
| Entry Transfer | 1 | 진입 속도 전달 비율. 1이면 새 진입의 접선 속도를 사용 |
| Recoil | 0.65 | 박차기의 반대 충격이 줄에 전달되는 비율 |
| Bend Limit | 0.14 | 몸통의 최대 휘어짐. 길이의 5% 이하로 제한 |
| Follow Time | 0.09 | 휘어짐이 따라오는 시간 |

이 값은 초기 튜닝 값이며 실제 연결 구간에서 확인 후 조정한다. 로프 길이를 바꾸면 속도와 도약 거리도 달라지므로 동일한 값이 같은 경로를 보장하지 않는다.

## X 흡수와 Z 박차기

방향키와 X의 기존 대상 선택 방식으로 끝에 들어간다. X를 누르기 직전 속도를 저장하고 부착 시 접선 성분을 전달한다. 흡수 이동 중 속도는 별도로 계산한다. 줄에 들어간 뒤 좌우로 반동을 키우고 Z를 누르면 그 순간의 스윙 방향으로 나온다. 위/아래 방향키가 이탈 방향을 지정하지 않는다. 정지 상태에서 Z를 누르면 추진력 없이 떨어진다.

플레이어의 새 로프 항목은 다음과 같다.

| 항목 | 초기값 | 의미 |
|---|---:|---|
| Rope Travel Speed Factor | 1.15 | 저장 속도의 크기가 흡수 접근 속도에 반영되는 비율 |
| Rope Travel Speed Limit | 36 | 접근 속도 상한. 끝을 따라잡기 위해 줄 끝 상한+2와 기존 흡수 속도 이상을 보장 |
| Rope Kick Boost | 4 | 스윙 방향의 추가 추진력 |
| Rope Air Acceleration | 8 | 공중에서 좌우 입력으로 궤도를 조절하는 가속도 |
| Rope Air Speed Limit | 30 | 이탈 속도와 이후 수평 속도의 안전 상한 |

Entry Transfer는 스윙에 넘기는 속도, Rope Travel Speed Factor는 줄 끝을 향해 이동하는 속도이므로 서로 독립적이다. 반동은 추가 추진력의 반대 충격이며 줄이 즉시 역방향으로 돌아야 한다는 뜻은 아니다.

이탈 후 입력을 놓아도 기세를 유지하며 반대 방향 입력은 점진적으로 감속한다. 착지, 일반 횃불 진입/발사, 스프링, 링/대시, 재시작이 다음 이동을 소유하면 기존 제어로 돌아간다. 스윙 중 제어 잠금은 일시 정지하며, 끝이 사라지거나 불이 초기화되면 안전하게 해제된다. R로 재시작하면 로프 초기 각도와 속도도 복원된다.

## 검증 기록 — 2026-10-06

Unity 6000.5.3f1의 별도 QA 프로젝트에서 기존 이동 35개와 로프/종료 처리 17개, 실제 Play Mode 연결 1개를 합쳐 **53개 통과, 실패·건너뜀 0개**를 확인했다. 결과는 `ValidationArtifacts/MovementFeel/Rope/VerifiedVisual/UnityResults.xml`, 화면은 같은 폴더의 `Captures`에 저장했다.

Play Mode는 프로젝트의 그래픽·품질 및 URP 설정을 복사했고 합성 키보드 입력과 정상 Update/FixedUpdate/네이티브 물리를 사용했다. 캡처 부하가 이탈 타이밍에 영향을 주지 않도록 QA에서만 프레임 시간을 1/60초로 고정했다. 실제 사람의 조작감 평가와 실행 파일 빌드는 하지 않았다.

초기값으로 횃불→첫 줄→둘째 줄 연결이 가능했다. 둘째 줄에서 빠르게 박차면 약 (18.59, 1.82)의 속도로 나와 착지 지점 (10.95, 0.41)에 도착했고 R로 처음 위치를 복원했다. 플레이어의 진입 속도를 크게 높여도 줄 끝 24, 이탈 30의 상한을 넘지 않는 검사도 통과했다. 이 수치는 검증용 배치에서 확인한 값으로, 최종 방의 길이와 간격에 맞춰 다시 조정할 수 있다.

테스트 씬은 `RopeValidationParticles.mat`를 사용해 불꽃과 발사 링에 기본 파티클 머티리얼을 명시한다. 씬 종료 중 잔상 풀이 먼저 제거되는 경우에도 안전하게 정리하도록 기존 잔상 처리에 null 검사를 추가했다. 원본 `Assets/Scenes/2.unity`와 프로젝트 설정은 변경하지 않았다.
