# Ember — 20분 정밀 이동·액션 퍼즐 상세기획 v1

작성일: 2026-10-03.
상태: 개발 검토용 상세 제안. 사용자가 선택한 콘셉트는 **현재 앰버: 불꽃 점화·흡수·발사 중심**이다. 목표는 셀레스트에서 원하는 정밀 이동·액션 퍼즐의 감각과 짧은 추격전을 갖춘 약 20분의 첫 플레이다. 아래 조작 배치, 이동 기준, 방 배치와 공격 수치는 구현·플레이테스트로 조정할 제안이며 아직 적용되지 않았다.

이번 범위에는 빛 소모, 거울 반사, 수정 분광, 물·비·불붙는 로프를 포함하지 않는다. 최근의 빛 콘셉트는 비교 아이디어로 남긴다. 기존 재설계 초안에 적힌 5개 방과 사격 중심안 대신, 이번 제작 범위는 이 문서의 12개 번호 방을 기준으로 검토한다.

## 1. 게임이 주는 재미

**불을 붙여 이동 거점을 만들고, 어느 거점에서 어떤 방향으로 출발할지 읽은 뒤, 점프·흡수·발사·대시를 정확하게 연결해 돌파한다.**

퍼즐은 행동 순서·거점 선택·출발 방향에 있다. 액션은 점화할 위치, 흡수할 순간, 착지 위치와 대시 사용 시점에 있다. 긴 스위치 조작, 숨겨진 해답, 기다리는 시간으로 분량을 늘리지 않는다.

한 방은 다음 구조를 가진다.

1. 안전한 시작점에서 출구와 핵심 거점을 읽는다.
2. 작은 실패로 규칙 또는 타이밍을 파악한다.
3. 2~4개의 동작을 연결해 짧은 난관을 넘는다.
4. 착지하거나 불에 들어가 숨을 고른다.
5. 앞에서 배운 동작을 조금 변형한 마지막 난관을 넘는다.

실패의 원인을 플레이어가 설명할 수 있어야 한다. 의도한 점프보다 입력 지연·목표 오선택·콜라이더 복원 문제가 먼저 보이면 레벨 난이도를 올리지 않는다.

### 한 장면으로 묶는 이야기·분위기 제안

데모의 장소는 **꺼진 회랑**, 목적은 끝의 큰 횃불을 다시 켜 폐허 정원에 온기를 돌려주는 것이다. 작은 불꽃인 앰버가 회랑의 거점을 깨우자 봉인된 어둠이 움직이고, 마지막에는 살아난 정원으로 탈출한다. 이는 이번 레벨을 묶는 최소 연출안이다.

| 막 | 플레이와 함께 전달할 장면 |
|---|---|
| 1 | 작은 불이 처음 켜지고 주변 식물 하나가 반응한다. 플레이어의 행동이 장소를 바꾼다. |
| 2 | 연결된 문과 오래된 통로가 깨어난다. 더 깊은 곳에 큰 목적지가 보인다. |
| 3 | 거점 사이 이동이 빨라지는 동안 배경의 어둠이 조금씩 가까워진다. |
| 4 | 어둠이 직접 방해한다. 마지막 횃불을 켜고 안전한 정원에서 긴장을 풀어준다. |

텍스트 설명은 시작·끝의 짧은 문장 정도로 제한한다. 배경 변화는 기존 조명·식물 애니메이션을 재사용한다. 전용 NPC·보이스·긴 컷신을 만들지 않아도 목표와 결과가 보이게 한다.

### 셀레스트에서 참고할 관점

입력·위치에 약간의 여유를 주면서 이동 자체의 도전은 유지한다. Maddy의 [Celeste & Forgiveness](https://www.maddymakesgames.com/articles/celeste_and_forgiveness/index.html)는 코요테 타임, 점프 버퍼, 정점 중력과 모서리 보정 등 플레이어의 의도를 받아주는 규칙을 설명한다. Ember에서는 이 원칙을 현재의 거점 이동에 적용한다. 셀레스트의 숫자·스테이지를 그대로 복사한다는 뜻은 아니다.

## 2. 플레이 대상과 완성 범위

- 대상: 2D 플랫폼 게임의 이동·점프에 익숙하지만 Ember는 처음인 플레이어.
- 첫 플레이 목표: 주 경로 완료 중앙값 18~22분. 넓은 허용 범위는 15~25분.
- 숙련 무실패 플레이: 약 7~10분을 가설로 둔다. 현재 측정값이 아니다.
- 구성: 4막, 12개 번호 방. 마지막 12번은 A/B/C의 짧은 인접 방으로 나누므로 지도 블록아웃은 총 14개다. 방 안의 중간 체크포인트까지 세면 고정 재시도 구간은 20개다.
- 선택 도전: 방 5·8·10에 각각 하나. 20분 주 경로 예산에 포함하지 않는다.
- 핵심 환경 장치: 횃불과 횃불 문. 움직이는 발판은 필수 구간에서 제외해 초기 자산·물리 검증 범위를 줄인다.
- 추격자: 한 종류, 예고 후 직선 돌진 한 패턴. 최종 구간에서 빈도·배치만 변형한다.
- 필수 새 기능: 조작 정리, 방 단위 재시작·진행, 거점 내부 추격 판정, 끝 화면.

## 3. 능력의 역할과 실행 계약

기획의 실행순서는 키 이름보다 행동 이름으로 적는다.

| 기호 | 행동 | 역할 | 자원/회복 |
|---|---|---|---|
| J | 일반·공중 점프 | 위치 조절과 짧은 지형 통과 | 공중 점프 1회. 접지·불 진입 시 회복 |
| I | 주변 점화 + 링 | 가까운 횃불을 켬, 공중에서 다음 행동을 고를 짧은 정지 | 링 사용권 1회. 접지·불 진입 시 회복 |
| A | 흡수 | 켜진 거점에 도달 | 범위와 유효 경로 필요. 자체 잔량 제한 없음 |
| L | 불에서 플레이어 발사 | 먼 거리 또는 높은 곳으로 출발 | 진입 시 자원 회복 후 방향 발사 |
| D | 링 대시 | 중간 구간에서 이동 방향 변경 | I의 사용권을 공유. I 이후에 실행 |
| S | 불씨 사격 | 가까이 접근할 수 없는 횃불을 켬 | 링에서 발사하며 I/D와 사용권 공유. 선택 도전만 필수 |

### 확정해 구현할 계약의 제안

1. 이동 성능은 모든 방에서 같다. 방별 속도 변경으로 해법을 만들지 않는다.
2. I는 주변을 즉시 점화한다. 링은 기본 0.3초의 선택 상태이며, 링을 만든다고 방의 위험물이 멈추지는 않는다.
3. **링 중에도 독립된 A 입력을 받는다.** 유효 목표라면 링을 취소하고 흡수한다. 현재 코드는 링 중 X가 사격이므로 이 규칙은 추가 개발 항목이다.
4. 링에서 D 또는 S를 쓰면 그 링은 끝난다. 다시 접지하거나 거점에 들어오기 전에는 새 링을 쓸 수 없다.
5. 유효 목표가 없을 때 A는 자원을 소비하거나 캐릭터를 멈추지 않는다. 실패 이유를 범위/장애물/꺼진 거점으로 구분한다.
6. 불꽃에서 발사할 때 방향 표시를 보고 실행한다. 무입력 발사는 위쪽으로 통일한다.
7. 흡수 목표와 발사 방향이 갑자기 다른 목표·각도로 바뀌지 않는다. 성공을 돕는 보정은 작은 위치·입력 여유에 한정한다.
8. 첫 구간의 횃불은 켜진 후 유지된다. 제한 시간 뒤 꺼지는 횃불은 없다. 사망 시 재시도 구간의 초기 상태로 복원한다.
9. 첫 20분의 A는 일반 몸 콜라이더가 통과할 수 있는 직선 경로로 통일한다. 현재의 큰 경유점 자동 우회는 이 빌드에서 사용하지 않는다. 목표 표시와 이동이 같은 경로 검사를 공유한다.
10. D는 선택한 키보드 8방향을 유지하며 장애물을 피하기 위한 자동 방향 회전을 하지 않는다. 일반 점프의 작은 모서리 보정은 유지하되, 대시 콜라이더만 통과할 수 있는 틈은 필수로 사용하지 않는다.

### 입력 충돌과 실패 처리

- 매 프레임 모든 상태에서 held/pressed/released를 갱신한다. 한 번의 pressed를 상태가 바뀐 뒤 다시 소비하지 않는다.
- 사망·R·일시정지를 먼저 처리한다. 이동 능력 처리 중 사망하면 같은 프레임의 나머지 능력을 실행하지 않는다.
- 일반 상태에서 I와 A가 함께 들어오면 I로 점화한 다음 목표를 다시 판정해 A를 실행한다. 유효한 A가 있으면 Space 요청은 이번 프레임에 실행하지 않는다.
- 링에서 A와 Space가 함께 들어오면 유효한 A가 우선이다. A가 불가능하면 Space의 D를 실행할 수 있다. 불 내부도 유효한 A가 L보다 우선이다.
- I와 Space가 함께 들어오면 해금된 D를 한 번 실행한다. D 해금 전에는 I만 실행하고 점프를 같은 프레임에 추가하지 않는다. 안내는 능력을 순서대로 눌러도 성공하는 방식으로 보여준다.
- I 후 링의 0.3초가 끝나도 켜진 목표가 A 범위에 있으면 흡수할 수 있다. 첫 횃불 학습을 0.3초 반응 시험으로 만들지 않는다.
- A 불가 시 꺼짐·거리·막힘 표시만 반응하고 기존 속도·자원은 유지한다. 화면에 정상 경로로 표시한 A가 이동 도중 막히면 기획상 실패가 아니라 경로 판정 결함으로 기록한다.

### 조작 제안과 현재 코드의 차이

사용자는 WASD·Shift·Space·마우스 사용을 계획했다. 아래는 기존 C+Z의 능력 구조를 유지하는 첫 키 배치안이다. 사격을 자유롭게 상시 사용하는 별도 설계는 이번 주 경로에 넣지 않는다.

| 입력 제안 | 일반 상태 | 링 상태 | 불 내부 |
|---|---|---|---|
| A/D | 수평 이동 | 발사 방향 선택 | 발사 방향 선택 |
| W/S | 방향 선택 | 발사 방향 선택 | 발사 방향 선택 |
| Space | J | D | L |
| Shift | I | 추가 사용 없음 | 첫 버전에서는 별도 행동 없음 |
| 마우스 오른쪽 클릭 | A | A: 링 취소 후 흡수 | A: 다음 거점으로 이동 |
| 마우스 이동 | 흡수 목표 선택 | 흡수 목표·선택 사격 조준 | 다음 흡수 목표 선택 |
| 왼쪽 누르기/놓기 | 첫 버전에서는 별도 행동 없음 | S 조준/발사 | 별도 행동 없음 |
| R / Esc | 구간 재시작 / 일시정지 | 같음 | 같음 |

플레이어 L/D는 키보드 8방향, 흡수 목표와 S는 마우스로 고르는 안이다. 플레이테스트에서 양손 부담이 크면 목표 선택을 키보드 방향으로 돌리고 마우스는 S만 담당하는 비교안을 사용한다. 이동 원본 X와 정규화된 조준 벡터는 분리한다.

현재 입력은 방향키·Z/X/C이고 위 배치는 미구현이다. 먼저 행동 계약을 구현하고 한 조작안으로 테스트한다. 방마다 조작을 바꾸거나 본편에 실험 배치를 섞지 않는다.

### 단계적 해금

| 시작 방 | 사용 가능 범위 |
|---|---|
| 1 | J만 |
| 2 | J/I/A/L. I→A를 먼저 소개하고 첫 진입에 위쪽 L 안내 |
| 3 | L의 키보드 8방향 선택을 응용 |
| 7 | D 추가 |
| 8 | S는 P2 선택 실험 구간에서만 소개. 주 경로에서는 계속 잠금 |

접근 가능한 능력과 UI 안내가 같아야 한다. 방 1~6의 해법을 아직 배우지 않은 D로 우회하게 두지 않는다. 이는 현재 PlayerAbilityUnlocks 기반을 활용하는 제안이다.

L은 별도 잠금 플래그를 만들지 않는다. A가 열리는 방 2부터 불 내부에서 항상 8방향 사용 가능하다. 처음 불에 들어갔을 때 위쪽 L 안내를 보여주고, 방 2에서 진입을 건너뛰었다면 방 3의 T1 진입 때 같은 안내를 보장한다. 방 2는 위쪽이 안전한 지형으로 만들며, 방에 따라 L 방향을 코드로 제한하지 않는다.

## 4. 이동 수치와 레벨 제작 기준

시작 기준은 `Assets/prefab/player.prefab`의 현재 수치다. `1.unity`의 별도 수치를 혼합하지 않는다. 수치는 고정하기 전 이동 시험 구간에서 검증한다.

| 항목 | 시작 기준 | 제작 의미 |
|---|---:|---|
| 이동 | 5 U/s | 수평 입력이 위/아래 조작에 따라 줄어들지 않도록 수정 |
| jumpSpeed / 실제 출발 | 7 / 약 8.28 U/s | 실제 출발은 상승 중력 보정에 따른 값 |
| 공중 점프 | 1회 | 평범한 구덩이만으로 횃불 사용을 강제할 수 없음 |
| 코요테/버퍼 | 0.12/0.12초 | 필수 해법은 유예를 악용해야만 성공하도록 만들지 않음 |
| 주변 점화 반경 | 2 U | 초반 의도한 횃불은 1.4~1.8 U 안에 놓고 경계만 강조 |
| 흡수 범위 | 4 U | 필수 A 연결은 시작 기준 3.2~3.6 U 이내, 전체 경로 충돌 확인 |
| 불 발사 | 10 U/s | 기존 SampleScene의 12를 혼합하지 않음 |
| 대시 최대/가속/시간 | 16 / 0.05초 / 0.15초 | 단순 16×0.15를 실제 이동 거리로 간주하지 않음 |
| S 속도/사거리 | 16 U/s / 8 U | 원거리 점화와 근거리 흡수 역할을 분리 |
| 기본 물리 스텝 | 0.02초 | 짧은 예고와 입력 창은 50Hz에서 확인 |

U는 Unity 월드 단위다. 현재 프리팹의 연속시간 점프 높이는 약 1.39 U, 정점 시간은 약 0.35초로 추정된다. 이것은 실행 측정이 아니며 접지 스텝·릴리스·충돌·공중 제어를 포함한 최종 이동 예산은 실제 테스트가 필요하다.

### 좌표보다 먼저 측정할 도구

실제 컨트롤러로 다음을 기록해 레벨 제작자가 쓰는 눈금으로 만든다.

- HJ: 버튼 유지 단일 점프의 최대 높이.
- HJJ/GJJ: 공중 점프를 포함한 높이/동일 높이 착지 간격.
- GL(dir), HL(dir): 각 방향 L 후 착지 범위와 높이.
- GD: D의 실제 이동 구간과 종료 이후 착지 범위.
- GJD/GJJD: 점프·공중 점프·대시를 조합한 최대 우회 범위.
- WB/HB: 실제 이동 콜라이더의 월드 폭/높이. 스프라이트 크기로 대체하지 않는다.

일반 필수 도전은 측정된 이동 한계의 65~80%에서 출발한다. 후반은 80~90%를 후보로 두되 반복 확인한다. 선택 도전만 더 좁은 창을 쓴다. 이 비율은 튜닝 기준이지 성공률 보장치가 아니다.

초반 착지면은 3×WB 이상, 중반은 2~3×WB, 후반은 1.5~2×WB를 출발점으로 삼는다. 필수 통로는 HB+0.12 U 이상으로 잡아 보정 없이는 물리적으로 끼는 해법을 피한다. 콜라이더 복원 안전성은 별도 검사한다.

기준 시험의 첫 블록은 일반 점프 높이 0.8~1.0 U, 같은 높이의 점프 틈 2.0~2.6 U, 대시가 직접 가로질러야 하는 구간 1.6~1.9 U에서 시작한다. 이는 현재 코드 추정에 대한 보수적인 시험 크기이며 이단점프·발사로의 우회 방지 크기는 아니다. A 후보 탐색은 목표 콜라이더를 포함하므로 실제 중심 간 거리 4 U를 정확한 계약으로 가정하지 않는다.

현재 I와 자동 불 전파는 벽 차폐를 검사하지 않는다. 첫 제작안은 I의 원형 영향 범위를 그대로 쓰되, 벽이 점화를 막아야만 풀리는 퍼즐은 만들지 않는다. 서로 독립적인 거점은 전파 반경 1.35 U 밖에 두고 다른 방도 가까이 겹치지 않게 배치한다. 벽으로 막힌 A와 벽 너머 점화 가능 여부는 UI에서 구별한다.

레벨의 외곽 크기와 숫자는 아래에 적지만 정확한 도약 좌표는 측정 후 배치한다. 단순히 높은 벽을 추가해 원하는 기술을 강제하지 않는다. 가능한 J/JJ/L/D 우회 경로를 함께 확인한다.

## 5. 20분 시간 예산과 감정 곡선

## 6. 방별 상세 설계

아래 크기는 초기 회색 블록아웃의 외곽 W×H다. 약 16×9 U를 한 화면 가설로 삼되, 실제 카메라와 캐릭터 크기를 확인한다. 화면 전환 전 착지·목표와 위험 예고가 보이도록 조정한다.

### 01 — 작은 불꽃의 발걸음 / 70초 / 약 22×9 U

- **질문:** 짧은 점프와 공중 점프를 어떤 순서로 사용할까?
- **배치:** 시작 안전 바닥 → 낮은 단차 2개 → 낮은 천장 아래 짧은 점프 → 공중 점프가 필요한 넓은 틈 → 출구. 첫 구간 밑에는 회수 바닥, 마지막 틈만 위험 바닥.
- **정답 실행:** 이동 → 짧은 J → 긴 J → 마지막 틈에서 J/J. 낮은 천장 구간은 버튼 릴리스의 효과를 보여준다.
- **안내:** 해당 위치에서 이동/점프 키만 표시. 모든 조작 목록을 한 화면에 펼치지 않는다.
- **실패:** 천장에 부딪혀도 첫 구간은 회수 가능. 마지막 틈 실패는 그 틈 직전에서 재시도한다.
- **검증:** 짧은/긴 점프를 구분하고 Space를 한 번 누른 상태로 공중 점프가 자동 반복되지 않는다. 코요테·버퍼가 체감되는지 관찰한다.
- **가설 실패 수:** 0~1회. 입장 5초 소개는 최초 한 번만 표시하고 건너뛸 수 있다.

### 02 — 첫 횃불 / 80초 / 약 18×10 U

- **질문:** 불붙은 횃불이 왜 이동 장소가 되는가?
- **배치:** 안전한 시작대의 I 범위 안에 꺼진 거점 T1. T1로의 A 경로에 작은 위험 구간을 두고, T1 위에는 넓은 출구 받침대를 둔다. 다른 방향으로 나가도 안전한 바닥에 떨어진다.
- **정답 실행:** T1 가까이 이동 → I → A. 첫 진입에 위쪽 방향 표시와 Space의 L 안내를 보여준다 → 위 L → 출구 받침대 착지. 방 3에서는 안전대에서 시작해 방향 선택을 응용한다.
- **설계 주의:** I/A는 바닥에서 여유 있게 누를 수 있게 한다. 이 방은 거점을 켜고, 들어가고, 밖으로 나오는 상태 변화가 학습 목표다. 임의 탈출 트리거를 추가하지 않는다.
- **피드백:** 점화 시 목적지 테두리·연결선이 켜지고, 진입하면 자원 아이콘이 회복된다. 불 자체는 위험물과 다른 색·형태를 쓴다.
- **실패:** 꺼진 횃불은 A 표시가 안 뜬다. 위험 구간은 짧게 복귀한다. 링 중 A가 먹히지 않는 입력 혼란은 구현 결함으로 분류한다.
- **검증:** 직접 걷기/JJ로 T1을 건너뛰어도 방 3에서 최소 한 번 진입을 배우는 구조인지 확인한다. 진입을 강제하는 숨은 능력 검사 대신 지형과 명시적 점화 목표를 사용한다.

### 03 — 불에서 튀어나오기 / 90초 / 약 20×13 U

- **질문:** 같은 불에서 위쪽과 대각선 발사는 어디로 이어질까?
- **배치:** 켜진 T1 위 안전 받침대 → 우상향의 꺼진 T2 → 모퉁이 너머 출구. T1→T2는 바로 A가 닿지 않지만 위 L로 올라간 안전대에서는 I/A가 닿는다. 출구 위치는 카메라로 미리 보여준다. L을 잘못 고르면 안전대에 내려온다.
- **정답 실행:** A(T1) → 위 L로 안전대 → I로 T2 점화 → A(T2) → 우상향 L → 착지. 발사 방향 2개를 한 방에서 비교한다.
- **액션:** L 후 수평 제어가 복구되는 시점에 착지를 조절한다. 첫 착지면은 넓고, 마지막만 조금 줄인다.
- **체크포인트:** 첫 안전대에서 T2를 실제로 점화한 뒤 후반 재시도 구간을 확정한다. 후반은 안전대·T1/T2 켜짐 상태로 재시작해 이미 성공한 점화를 반복하지 않는다. T2 점화 전에는 전반 시작 상태로 복원한다.
- **검증:** 발사 화살표와 실제 방향 일치. 무입력 L은 위쪽. 실패해도 불 안에 다시 들어갈 수 있다.

### 04 — 공중에서 길 만들기 / 90초 / 약 20×12 U

- **질문:** 지상 I로 닿지 않는 횃불은 어디에서 켜야 할까?
- **배치:** 출구 쪽 높은 거점 T1을 출발 바닥의 I 범위 밖에 둔다. 점프 상승 구간의 넓은 영역에서 1.4~1.8 U 안에 들어오게 한다. T1 위/옆 지형은 불 진입 후 L로만 자연스럽게 출구에 연결한다.
- **정답 실행:** J → 공중 I로 T1 점화 → 링 중 A → L → 착지. 이단점프는 실패 복구로 남긴다.
- **액션:** 공중 점화 위치를 고르는 재미. 처음에는 안전한 회수 바닥, 두 번째 변형에서만 위험 바닥.
- **리스크:** I를 너무 일찍 쓰면 닿지 않고 공중 사용권이 없다. 회수 바닥에 착지하면 다시 사용할 수 있다. 맞췄을 때 반응은 즉시 보여준다.
- **우회 검사:** 단순 JJ로 출구에 닿는지 측정하고 목표 위치·지형을 조정한다. 불필요하게 창을 줄이지 않는다.

### 05 — 뒤로 가야 열리는 길 / 100초 / 약 22×13 U

- **질문:** 앞쪽 거점이 항상 좋은 출발점일까?
- **배치:** 시작에서 보이는 켜진 앞쪽 T_A와 약간 뒤쪽/아래쪽의 켜진 T_B. T_A 위에는 낮은 천장, T_B 위에는 출구 방향으로 열린 대각선 통로. 두 거점 모두 접근 가능하지만 T_A에서 출구 쪽 거점으로의 A는 장애물로 막힌다.
- **정답 실행:** I/A(T_A)로 상황 관찰 가능 → T_B 선택해 A → 대각선 L → 출구. T_B를 처음부터 선택한 플레이어도 허용한다.
- **퍼즐:** 최단 거리보다 출발 방향과 통로가 중요하다. 목표선은 막힌 경로를 별도 표시한다. 막힌 목표로 이동하다 멈추는 것을 정답 발견 방식으로 강요하지 않는다.
- **실패:** 잘못된 거점에서도 안전하게 되돌아올 수 있다. 위치 이동 퍼즐을 조준 정확도 시험으로 바꾸지 않는다.
- **선택 도전:** T_A 쪽 좁은 우회로에서 작은 불씨 표식 획득. 수집 구현 전에는 장식/짧은 추가 이동 루프로 먼저 검증한다. 필수 출구와 분리한다.
- **검증:** A 자동 우회가 벽을 돌아 T_A→출구를 허용하지 않는다. 방별 임의 범위 제한 대신 동일한 경로 규칙으로 해결한다.

### 06 — 닫힌 회랑 / 110초 / 약 24×12 U

- **질문:** 점화할 순서와 이동할 순서는 같을까?
- **배치:** 출구 문은 점화 횃불 T1/T2와 눈에 보이는 선으로 연결된다. T1은 쉽게 켤 수 있고, T2는 T1 발사를 활용해 올라가는 중간 발판에서 접근한다. 문 너머에 출구가 보인다.
- **정답 실행:** I(T1) → A/L → 중간대 착지로 I 회복 → I(T2) → 문 열림 → A(T2)/L → 출구 접근.
- **새 규칙:** 두 횃불 점화가 문을 연다. 문 아래 빈칸 두 개가 각각 켜지는 시각 피드백으로 설명한다. 숫자 코드·순서 기억은 요구하지 않는다.
- **재시작:** 전반/후반을 분리한다. 후반 시작은 T1 켜짐·T2 꺼짐·문 닫힘의 명시적 상태다. 플레이어 위치만 저장해 불 상태와 충돌하지 않게 한다.
- **검증:** 자동 전파로 T1이 T2까지 켜서 방이 즉시 끝나지 않도록 배치한다. 연결되지 않은 횃불의 독립성이 시각적으로 드러나야 한다.

### 07 — 한 번의 방향 전환 / 90초 / 약 18×11 U

- **질문:** 발사 후 중간에서 방향을 바꿔야 한다면?
- **배치:** T1 위에 올라가는 경로, 상단에는 천장 위험물과 옆쪽 출구. 수직 L만 하면 천장에 닿고, 공중 J만으로는 옆쪽 착지점에 안정적으로 닿지 않는 측정된 배치를 만든다.
- **정답 실행:** A(T1) → 위 L → 위험 전에 I → 오른쪽 D → 넓은 착지대. 첫 시도 아래 회수 바닥, 두 번째 반복에만 위험물을 넣는다.
- **안내:** 링 중 Space가 D라는 표시를 해당 지점에서 보여준다. I와 D를 동시 누르기 대신 순서 입력으로 안내한다.
- **리스크:** D 사용 위치·방향을 고르면 그 방향으로 이동한다. 입력 방향으로 막히면 자동 회전하지 않고 충돌한다. 첫 반복의 안전 바닥이 이를 보여준다.
- **검증:** 위 L 도중 I로 속도가 멈추는 것과 D가 정상적으로 이어진다. 종료 후 콜라이더가 겹치지 않는다.

### 08 — 어디에 착지할까 / 100초 / 약 24×10 U

- **질문:** D를 빨리 쓰는 것과 다음 사용권을 확보하는 것 중 무엇이 중요할까?
- **배치:** 첫 틈 뒤 낮은 착지대 P와 공중 거점 T. 멀어 보이는 출구로 바로 D하면 두 번째 틈에서 사용할 자원이 없다. P에 착지하거나 T에 들어가는 경로는 사용권을 회복하고 다음 D가 가능하다.
- **정답 실행:** J/I/D → P 착지로 회복 → J/I/D 또는 A(T)/L → 출구. 착지 경로와 거점 경로 두 해법을 허용한다.
- **피드백:** 자원 회복 시 링 아이콘과 짧은 소리. 실패 시 UI가 비어 있으면 왜 D가 안 나갔는지 이해할 수 있다.
- **체크포인트:** 첫 착지대 P. 반복 실패는 두 번째 틈만 재시도.
- **선택 S 실험:** P2에서 별도 안전 샛길을 열 때만 S를 사용 가능하게 한다. I 범위 밖·A 후보 탐색 밖·S 범위 안의 횃불을 겨누어 켠 뒤, J로 흡수 범위 안에 접근한다. 본편 출구 조건과 연결하지 않는다. 샛길 출구에서 S는 다시 잠그며 미완성일 때는 샛길을 닫고 주 경로는 그대로 둔다.

### 09 — 불꽃 릴레이 / 110초 / 약 28×14 U

- **질문:** 이동을 멈추지 않으면서 어디에서 자원을 회복할까?
- **배치:** 켜진 세 거점이 지그재그로 놓인다. T1→T2는 L 후 A, T2→T3는 L/I/D 후 접근, T3→출구는 방향 L과 착지. 연속 직선 A만으로 모두 건너뛰지 못하도록 벽·높이·범위를 구성한다.
- **정답 실행:** A(T1)/L → A(T2) 회복 → L/I/D → A(T3) 회복 → L/J → 출구.
- **리듬:** 발사 1~2초 → 이동/흡수 → 짧은 목표 선택 → 재출발. 링을 매번 길게 기다리는 구간을 넣지 않는다.
- **실패:** 중간 거점 T2를 후반 시작점으로 고정한다. 후반 길이는 숙련 실행 약 10~15초를 후보로 삼는다.
- **검증:** 사격 없어도 주 경로가 풀리고, 과도한 자동 경로 우회 없이 요구된 연결이 가능하다. 모든 거점 체류는 여기까지 안전하다.

### 10 — 고요한 전조 / 100초 / 약 24×10 U

- **역할:** 3막 뒤 부담을 낮추고 추격 규칙을 안전하게 보여준다.
- **배치:** 익숙한 J/I/A/L 경로 1개, 쉬운 횃불 문, 멀리 봉인된 어둠의 존재. 안전 창 너머에서 예고→직선 돌진→회복을 한 번 보여준다.
- **정답 실행:** 기존 경로로 장치를 켠다 → 출구 근처에서 추격자가 풀려나는 모습을 본다 → 짧은 연결 통로를 지나 방 11 시작.
- **안내:** 링은 세계를 멈추지 않는다는 것을 움직이는 추격자의 시각·음향으로 보여준다. 아직 플레이어를 공격하지 않는다.
- **연출:** 첫 방문에 5~8초 이내, 재시도에서는 생략. 대사와 강제 대기로 시간을 채우지 않는다.
- **선택 도전:** 안전 경로 위쪽에 짧은 L/D 착지 루프. 완료 시 장식 꽃 또는 불씨 표식 반응. 애셋은 기존 것을 재사용한다.

### 11 — 첫 추격 / 110초 / 2개의 약 18×10 U 구간

- **질문:** 언제 떠나야 공격을 피할 수 있을까?
- **배치:** 방 4의 공중 점화와 방 7의 방향 전환을 쉬운 간격으로 재사용. 첫 구간은 두 거점, 둘째는 거점 1개와 착지대. 각 시작점은 안전하며 출구가 미리 보인다.
- **정답 실행:** J/I/A → L로 첫 돌진 피하기 → 착지/거점 회복 → L/I/D로 다음 돌진 피하기.
- **추격:** 첫 준비 창은 길게, 공격은 직선으로 잠근다. 첫 실패도 어떤 궤적이었는지 잔상으로 남긴다.
- **체크포인트:** 두 구간 사이 안전대. 첫 진입 연출은 반복하지 않는다. 새 퍼즐 규칙·새 키를 추가하지 않는다.
- **검증:** I의 0.3초 정지 중에도 공격은 같은 세계 시간으로 계속 진행한다. 거점에 무한히 머물 때의 판정은 다음 추격 계약을 따른다.

### 12 — 마지막 회랑 / 150초 / A·B·C 각 약 20×12 U

- **역할:** 앞선 이동 문제를 짧은 연속 장면으로 완수하는 절정.
- **12A:** J/I/A로 거점 확보 → 우상향 L → 예고된 수평 돌진 회피. 방 4+11의 응용.
- **12B:** 뒤쪽 거점에서 시작해야 다음 통로가 열린다 → L/I/D → 착지 회복. 방 5+8의 응용.
- **12C:** T1→T2 릴레이 → 마지막 돌진을 보고 방향 L/D → 출구. 방 9의 응용.
- **체크포인트:** A/B/C는 고정 초기 상태의 독립 재시도 구간이다. 실패 시 해당 구간만 복원한다. 이동 블록·불 상태의 임의 중간 스냅샷을 구현할 필요가 없다.
- **성공 연출:** 마지막 횃불이 켜지고 작은 폐허 정원에 따뜻한 불빛이 돌아온다. 기존 식물/조명 변형을 사용하고 약 10~15초 뒤 완료 화면과 다시하기를 제공한다.
- **난이도:** 마지막이 가장 어렵지만 한 번의 필수 입력 창을 이전 구간의 절반으로 줄이지 않는다. 같은 패턴의 연속 수행과 거점 선택으로 절정을 만든다.
- **검증:** 어느 방향으로 나가도 소프트락이 없고, 사망·R에서 공격 예고와 횃불 초기 상태가 같아야 한다.

## 7. 대표 동선의 개념도

기호: S 시작, E 출구, T 불꽃 거점, P 착지대, X 위험. 아래는 논리 도식이며 정확한 충돌·좌표 배치도가 아니다.

```text
방 04: 공중에서 길 만들기
                 T1 ── L ──> P ──> E
                  ↑ A
          J → I [공중 점화 구간]
        S         XXXXXXXXXXX

방 08: 사용권과 착지 선택
        S ─ J/I/D ─> P [회복] ─ J/I/D ─> E
                        ↘ A(T) → L ↗
        XXXXXXXXX    XXXXXXXXXXXX

방 12: 압박 속 재조합
        12A 시작 → 공중점화/발사 → 안전 경계
        12B 시작 → 거점 선택/방향 전환 → 안전 경계
        12C 시작 → 연속 이동/마지막 회피 → 끝
        각 구간에 예고→돌진→회복. 죽으면 해당 구간 시작.
```

각 방은 보이는 목표, 허용되는 이동 연결, 출구 조건을 그래프로도 작성한다. 성공 해법이 적어도 하나 있고 자원 부족 상태에서 회수 또는 즉시 재시도가 가능해야 한다. 대체 해법은 의도한 위험·시간의 대가가 있으면 허용한다.

## 8. 추격자 상세 계약

### 한 패턴의 상태

`진입 대기 → 준비/방향 예고 → 목표 방향 잠금 → 직선 돌진 → 회복 → 다음 준비`

첫 구현은 방에 정한 출현 지점과 구간을 사용한다. 복잡한 길찾기, 무조건 플레이어와 같은 속도로 따라붙는 추적, 임의 순간이동은 넣지 않는다. 공격 후 다음 지점으로 이동할 때는 보이는 경로/화면 밖 안전 영역을 사용하며 공격 판정을 끈다. 화면 밖에서 공격을 시작하지 않는다.

| 항목 | 방 11 초기 제안 | 방 12 초기 제안 |
|---|---:|---:|
| 화면 내 준비/예고 | 1.2초 | 1.0~1.2초 |
| 목표 방향 잠금 | 돌진 0.25초 전 | 돌진 0.25초 전 |
| 돌진 이동 구간 | 약 0.5~0.7초 | 약 0.5~0.7초 |
| 회복 | 1.4초 | 1.0~1.2초 |
| 리스폰 후 시작 여유 | 1.0초 이상 | 1.0초 이상 |

수치는 보장값이 아니다. 실제 요구 경로의 최소 실행 시간과 초심자 반응 여유를 기준으로 조절한다. 속도는 공격 길이÷돌진 시간을 기준으로 산정하고, 모든 방을 플레이어 속도 배수 하나로 맞추지 않는다. 이동 거리보다 읽을 수 있는 공격 궤적을 먼저 정한다.

### 불꽃 내부 안전과 위험

현재 Anchored는 몸 콜라이더를 끈다. 일반 적 접촉만으로 거점 안의 플레이어를 공격할 수 없으므로 별도 점유 상태 판정이 필요하다.

- 일반 방에서는 무제한 체류가 가능하다.
- 추격 구간에서는 추격자가 현재 점유 거점을 노리면 외곽 고리와 소리로 공격을 예고한다.
- 최소 초기 1.2초의 이탈 여유를 후보로 두고, 그 안에 L 또는 A로 떠나면 피한다.
- 예고 종료 시 여전히 해당 거점에 머문 경우 구간 사망 처리한다. 자동으로 위험한 위치에 강제 발사하지 않는다.
- 필수 횃불을 영구 소화시키지 않는다. 공격 후에도 경로는 다시 사용할 수 있다.
- 시간 압박이 적용되는 구간은 배경 효과와 입구 연출로 구분한다. 같은 조작이 설명 없이 갑자기 실패하지 않게 한다.

### 조준 슬로모션 정책

현재 S 조준은 링 시간을 멈추고 전역 시간을 0.3배로 바꾼다. 첫 제작안에서는 **주 경로 전체에서 S를 잠그고, P2의 방 8 안전 샛길에서만 허용한다.** 따라서 추격 방에는 조준 슬로모션과 무제한 링 정지가 없다. 샛길 종료·사망·R에서 조준을 취소하고 시간 배율을 반드시 복원한다.

추격자의 모든 상태는 같은 게임 시간으로 갱신하고 Esc 일시정지에 함께 멈춘다. 나중에 S를 주 경로로 확장한다면 조준 상한·시간 정책과 사격/대시 사용권 선택을 별도로 설계하고 안전 구간에서 가르친다.

## 9. 위험과 보상의 설계

새 체력·열·빛 게이지를 이번 범위에 추가하지 않는다. 능력의 위험은 도착 위치, 사용권, 실행 시점에서 나온다.

| 선택 | 이득 | 대가 |
|---|---|---|
| I를 지금 사용 | 주변 점화, 공중 속도 정지 | 착지/불 진입 전 다시 사용 못함. 추격은 진행 |
| D로 직접 돌파 | 빠르게 틈을 넘거나 방향 변경 | 잘못된 착지면 다음 링 사용권 없음 |
| A로 돌아가기 | 자원 회복, 다음 L 출발점 확보 | 경로를 다시 읽고 우회해야 함. 추격에서 머무르면 위험 |
| 작은 착지대 선택 | 짧은 경로 | 착지 정밀도 요구 |
| 넓은 우회대 선택 | 실패 복구 용이 | 더 긴 경로/추격 공격 한 번 더 피해야 할 수 있음 |

필수 해법을 정확히 실행해도 예측 불가능하게 죽는 위험은 제거한다. 실패를 쉬운 앞부분의 반복으로 처벌하지 않는다. 숙련자는 짧은 경로, 초심자는 안전한 경로를 선택할 수 있는 구간을 방 8에 둔다.

## 10. 재시작·진행·카메라

### 재시도 구간

번호 방과 체크포인트 구간은 구분한다. 각 구간은 고정 시작점, 초기 불 상태, 문 상태, 추격자 시작 상태를 가진다. 완료한 이전 구간은 되돌리지 않는다. 임의 시점 스냅샷 대신 명시된 초기 상태를 사용한다.

| 번호 방 | 고정 재시도 구간 | 후반 시작 상태 |
|---|---:|---|
| 01 | 2 | 마지막 넓은 틈 직전, 공중 점프 회복 |
| 02 | 1 | 처음부터 T1 꺼짐. 최초 L 안내 이력 유지 |
| 03 | 2 | 안전 받침대, T1/T2 켜짐 |
| 04 | 1 | 출발대, 목표 횃불 꺼짐 |
| 05 | 1 | 출발대, 두 선택 거점 켜짐 |
| 06 | 2 | 중간대, T1 켜짐·T2 꺼짐·문 닫힘 |
| 07 | 1 | 출발대, T1 켜짐 |
| 08 | 2 | 첫 착지대 P, 경로 거점 켜짐 |
| 09 | 2 | T2 안전 받침대, 세 거점 켜짐 |
| 10 | 1 | 출발대, 쉬운 문 조건 초기화. 최초 연출 이력 유지 |
| 11 | 2 | 중앙 안전대, 후반 거점 초기화·추격자 대기 |
| 12 | 3 | 각 A/B/C 시작대, 해당 거점 고정 상태·추격자 대기 |

총 20개이며 각 구간 시작에 점프·링 사용권을 회복한다. 거점 내부에서 리스폰하지 않고 그 옆의 명시된 안전 받침대에서 시작한다. 12A의 점화 대상은 꺼짐, 12B의 선택 거점과 12C의 릴레이 거점은 켜짐으로 시작한다. 선택 도전 완료 기록은 재시도로 삭제하지 않는다.

사망과 R은 같은 복원 경로를 사용한다.

1. 입력/링/사격 조준을 취소하고 시간 배율을 복원한다.
2. 해당 구간의 투사체·추격 예고·잔상을 정리한다.
3. 해당 구간의 횃불·문·적을 초기 상태로 복원한다.
4. 플레이어를 안전한 시작점에 놓고 속도·콜라이더·능력 사용권을 복원한다.
5. 카메라를 해당 시작점으로 복원하고 준비 입력을 받는다.

첫 기준은 사망부터 조작 복귀까지 0.5~0.8초 이하를 목표로 한다. 리스폰 후 키를 누르고 있었으면 방향 이동은 허용하되, 점프·발사·링의 새 pressed 동작이 의도 없이 발생하지 않게 한다. 더 빠른 즉시 복귀가 안전하면 지연을 추가할 이유는 없다.

### 진행과 종료

- 이번 빌드는 시작 화면 → 번호 방 순서 → 짧은 끝 화면으로 연결한다.
- 방/구간 완료 시 다음 구간 해금, 체크포인트 갱신, 카메라 이동을 한 경로에서 처리한다.
- 최소 저장은 마지막 완료 방과 선택 도전 완료 여부다. 프로세스 재실행 때 임의 중간 물리 상태를 복원하지 않는다.
- 첫 추격 연출과 끝 연출은 재시도에서 생략하며 Esc로 일시정지한다.
- 최종 화면에 총 플레이 시간, 사망 수, 재시작, 종료를 제공한다. 숫자는 플레이 평가용이며 점수 벌점을 주지 않는다.

### 카메라

- 다음 착지대·흡수 목표·공격 준비점이 이동 전에 보인다.
- 높은 발사 전에 위쪽 공간을 미리 보여준다. 공중에서 화면이 바뀌고 숨겨진 가시에 닿는 장면을 피한다.
- 안전 착지대/불 거점에서 카메라 이동을 마무리한다. 추격 도중 카메라가 플레이어보다 앞서 나가 조작을 가리지 않는다.
- 화면 흔들림은 짧게, 밝은 섬광은 목표 식별을 방해하지 않게 한다. 흔들림 낮춤/끄기 옵션을 최소 범위로 고려한다.

## 11. 아트·사운드·UI 제작량

환경 테마는 한 종류의 어두운 폐허/회랑으로 통일한다. 새로운 물·비·불타는 재료마다 상태를 만드는 방향은 제외한다. 불 전파는 첫 버전에서 독립된 횃불 사이에 임의 발생하지 않도록 배치하고, 필요하면 명시된 연결만 사용하는 기능을 별도 후보로 둔다.

| 항목 | 최소 제작물 | 재사용 방법 |
|---|---|---|
| 앰버 | 기존 대기/달리기/점프·체공 + 발사 피드백 점검 | 대부분 기존 스프라이트 활용 |
| 충돌 지형 | 타일셋 1종 | 방별 배치와 조명으로 분위기 변화 |
| 횃불 | 꺼짐/켜짐 + 진입/목표 표시 | 모든 거점에 공통 사용 |
| 횃불 문 | 닫힘/열림 + 두 불 표시 | 방 6·10에서 재사용 |
| 위험물 | 고정 위험물 1종 | 바닥/천장 위치만 변화 |
| 추격자 | 실루엣 1종 + 예고/돌진/회복 효과 | 별도 여러 적 종류 제작 없음 |
| 구간 시작 표시 | 시작점/불빛 표시 1종 | 모든 재시도 구간에서 재사용 |
| 선택 보상 | 작은 불씨 표식 1종, P2 후보 | 주 경로와 분리 |
| 끝 연출 | 기존 식물·조명 밝기 변화 | 대형 생물 애니메이션 제작 없음 |

필수 소리는 점프, 점화, 흡수, 플레이어 발사, 링 대시, 자원 회복, 사망/복귀, 문 열림, 추격 준비/돌진, 구간 완료다. 정확한 파일 개수보다 행동을 구분하는 것이 목적이다. 배경음은 기본 구간과 추격 구간의 2상태를 출발점으로 둔다.

UI는 링 사용 가능, 공중 점프 잔량, 선택된 흡수 목표를 작게 표시한다. 초반 설명은 그 방의 새 행동 한 가지씩만 보인다. 사거리 밖과 벽에 막힌 목표를 같은 정상 연결선으로 표시하지 않는다.

## 12. 현재 코드와 필요한 개발 작업

이미 기반이 있는 것: 기본/공중 점프, 링 점화, 흡수·불 발사, 링 대시·사격, 횃불 문, 위험물·방 시작점, 방 카메라, 파티클·잔상, 능력 해금.

### P0 — 레벨 제작 전에 해결

| 작업 | 이유 | 검증 |
|---|---|---|
| 단일 이동 설정을 새 빌드에서 공유 | 씬별 move/jump/gravity 차이로 배치가 달라짐 | 시험 구간과 모든 방의 수치 동일 |
| 이동/조준 입력 분리, 상태별 입력 갱신 | 상하 입력으로 X 속도가 줄고 비Free 상태에서 held/release가 멈춤 | 대각 조준 중 달리기, 능력 종료 중 버튼 누름/놓음 |
| 링 중 독립 A 처리와 입력 우선순위 | 공중 I→A가 핵심 해법 | 같은 프레임 I/A, A/D 충돌을 명시적 우선순위로 처리 |
| 흡수 가능 목표/경로 표시와 실제 캐스트 일치 | 막힌 목표 선택 후 정지는 해법 예측을 깨뜨림 | 범위 밖, 벽 뒤, 좁은 틈, 다중 목표 |
| 대시 자동 방향 회전 제거·Collider 복원 안전 | 현재 최대 66° 자동 회전과 축소 Collider 복원 위험 | 입력 8방향 유지, 바닥·벽·천장·좁은 대시 종료 |
| 구간 단위 초기화/진행 | 현재 Restart는 씬 전체 FlammableTile을 찾아 리셋 | 앞방 완료 유지, 현구간 불/문/적 복원 |
| 전체 조작 안내·R/Esc/제단 종료 입력 연동 | HUD/제단 등은 현재 방향키 기준 | 새 조작으로 잠긴 상태를 정상 종료 |

### P1 — 20분 주 경로 완성에 필요

- 12번호/14지도 블록아웃과 20개 재시도 구간, 능력 해금·안내.
- 추격자 한 패턴, 거점 점유 위험 판정, 리스폰 여유.
- 방 6·10의 횃불 문 연결과 초기 상태.
- 고정 구간 시작·출구 전환·카메라 연결·최소 저장·끝 화면.
- 주요 행동의 사운드와 현재 애니메이션 연결 확인.
- 테스트 기록: 방별 시간/사망 원인/입력 행동/체크포인트.

### P2 — 주 경로 뒤에 판단

- 방 8 S 선택 샛길과 마우스 사격.
- 선택 보상 수집/저장, 어려운 보너스 이동.
- 환경 장식, 추가 이야기, 고유 음악·애니메이션 확대.

움직이는 발판, 반사 퍼즐, 빛 잔량, 물, 복잡한 불 전파를 추가 작업 목록에 끼워 넣지 않는다. 해당 아이디어는 이번 데모 검증 이후 별도 검토한다.

## 13. 개발 순서와 중간 검토

1. **이동 기준 방:** 수치·조작·경로·재시작 P0. 완료 전 다른 방의 정확한 좌표를 확정하지 않는다.
2. **대표 방 02/04/07:** 거점 학습, 공중 점화, 링 대시를 먼저 제작한다. 이 세 장면이 성립하면 나머지 방에 재사용한다.
3. **방 01~06 연결:** 학습 순서와 처음 9분의 경로 퍼즐을 플레이테스트한다.
4. **방 07~10 연결:** 자원 선택과 연속 실행의 변화를 검증한다.
5. **방 11/12:** 같은 경로를 추격 없이 먼저 완주한 뒤 압박을 넣는다. 추격으로 물리·해법 문제를 덮지 않는다.
6. **첫 플레이 테스트와 수정:** 분량·실패 원인을 기준으로 수정한다. 이 단계에서 선택 S와 아트를 늘릴지 판단한다.
7. **배포 검증:** 실제 시작 씬과 저장·재시작·끝 화면, 빌드의 입력/카메라/효과를 확인한다.

일정은 작업량을 시간으로 추정한 뒤 별도로 세운다. “방 12개라 20분” 또는 “며칠이면 완성”이라고 확정하지 않는다.

## 14. 플레이테스트와 통과 기준

### 측정 정의

- 세션 시간: 실제 플레이 중 시간. 일시정지·테스터 인터뷰는 제외, 실패/복귀/선택 조준·짧은 연출은 포함.
- 방 시간: 입장부터 최초 주 경로 완료까지. 선택 샛길 시간은 별도 기록.
- 사망 원인: 고정 위험물 / 추격 / 링 부족 / 목표 오선택 / 충돌·끼임 / 불명.
- 경로 발견 시간: 정답 동작을 최초로 의도하기까지. 이후 실패는 실행 문제로 구분한다.
- 회복 시간: 사망부터 다시 조작 가능할 때까지.

처음에는 게임을 처음 보는 5명 정도로 소규모 탐색 테스트를 한다. 전반적인 성공률을 주장할 표본은 아니지만, 반복된 혼란과 분량 편차를 찾는 데 쓴다. 설계자 시범 없이 플레이하고 안내가 없어서 막힌 경우만 개입 여부를 기록한다.

### 목표와 대응

| 관찰 | 목표 가설 | 벗어났을 때 먼저 할 것 |
|---|---|---|
| 주 경로 첫 완료 | 중앙값 18~22분 | 대기 추가보다 방별 해법 이해/재주행 원인 확인 |
| 기본 학습 방 1~3 | 장시간 설명 없이 진입·발사 이해 | 같은 방에서 조작·퍼즐·타이밍을 동시에 가르쳤는지 확인 |
| 첫 3방 | 대체로 0~2회 사망/방 | 범위/키/목표 피드백과 안전 받침대 확인 |
| 중반 | 대체로 1~3회 사망/구간 | 실패 구간을 짧게 분리하고 원인 확인 |
| 추격 | 실패 뒤 회피 방법을 설명 가능 | 예고·화면 프레이밍·방향 잠금 먼저 조절 |
| 사망→복귀 | 0.5~0.8초 이내 후보 | 긴 연출·전체 씬 리셋·반복 앞부분 제거 |
| 동일 입력·동일 상태 | 같은 이동과 결과 | 프레임/시간 배율/입력 초기화 검증 |

사망 수는 강제로 만들 목표가 아니라 예상 난도 가설이다. 해법이 명확하고 숙련 실행이 재미있다면 초심자가 더 적게 죽는 것은 실패가 아니다. 어려움을 올릴 때는 착지 창·동작 연결·선택 경로 중 하나씩 바꾼다.

### 출시 전 최소 점검

- 모든 필수 방이 해금된 능력만으로 처음부터 완주 가능.
- 사격 선택 샛길 없이도 끝까지 통과 가능.
- J/JJ/L/D와 자동 우회로 필수 퍼즐 전체가 사라지지 않음. 의도된 지름길은 허용.
- 사망/R/다음 방/저장 재개에서 동일 구간 초기 상태와 시간 배율.
- 추격자가 Anchored를 무시하거나 필수 거점을 영구 파괴하지 않음.
- 새 키 배치로 안내·제단·재시작·일시정지가 모두 동작.
- 저/고 렌더 FPS에서 조작과 공격 예고가 일관됨. 물리 갱신과 별도로 검증.
- 회복 공간이 위험물과 겹치지 않고 Collider 복귀가 안전함.
- 최초 빌드 시작부터 마지막 종료까지 실제 빌드에서 확인.
