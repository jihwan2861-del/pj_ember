## 관찰

- 지상과 공중 발판은 완전히 다른 타일 종류가 아니라, 같은 지형 재료의 덩어리를 서로 다른 위치·크기로 배치한 것으로 읽힌다. 윗면·벽면·밑면·안쪽과 바깥쪽 모서리·중앙 채움이 기본 구조다.
- 한 테마 안에도 눈·푸른 암석, 갈색 흙/암석, 회색 건축 테두리, 어두운 내부가 함께 등장한다. 명암이 다른 배경 건물은 실제 충돌면과 분리되어 있다.
- 실제 발판 경계는 밝고 연속된 테두리로 읽히지만, 눈 더미·부스러기·균열은 칸 밖으로 삐져나와 반복을 숨긴다. 배경 쪽 장식과 짙은 빈 공간이 사각 덩어리의 인상을 줄인다.
- 공중 덩어리는 밑부분을 짧게 늘어뜨리거나 비대칭으로 끊어, 직사각형 블록처럼 보이지 않게 한다. 윗면의 점프 목표는 명확하다.
- 가시가 닿는 면과 안전하게 설 수 있는 면을 강한 실루엣 차이로 구분한다. 장식이 착지 가능 영역을 감추지 않는다.
- 이동 기믹은 주변에 큰 빈 공간을 두어 경로와 목적지를 먼저 읽게 한다. 시작·착지 장소가 작은 중간 목표보다 넉넉한 예를 볼 수 있다.

## Ember 낙서 스킨에 적용하는 기준

1. 충돌·방 크기는 기존 0.5U 타일과 36×20.25칸 카메라를 따른다. 셀레스트의 거리 수치를 그대로 복제하지 않는다.
2. 돌 그림 하나가 매 셀을 테두리로 감싸지 않도록, 2~4칸에 걸친 돌 덩어리·균열·색연필 얼룩으로 내부 격자를 숨긴다.
3. 윗면은 읽을 수 있게 유지하고, 수직벽·밑면·풀 끝에 작은 불규칙 선과 장식을 더한다. 가장자리의 장식 여유 0.05~0.1U는 시험 적용값이며 충돌은 바꾸지 않는다.
4. 외곽 모서리는 얕게 둥글리되, 보이는 착지면과 실제 착지면의 차이를 작게 유지한다. 세밀한 조작 재미는 이동 경계와 위험 경계를 읽을 수 있을 때 생긴다.
5. 한 화면에 지상 선반, 작은 공중 발판, 긴 수직벽, 천장 돌출부를 함께 시험 배치해 같은 스킨이 네 경우에 모두 연결되는지 확인한다.
6. 낙서 선은 검은색·짙은 회색, 바위는 따뜻한 회색, 풀은 황금색, 배경 산은 연한 청보라색으로 대비를 둔다. 플레이어·불꽃·태양꽃은 선명한 주황색으로 눈에 들어오게 한다.

이는 캡처를 보고 정리한 제작 제안이다. 원본 타일 아틀라스 전체나 모든 타일 조합을 추출·확인했다는 의미는 아니다.
