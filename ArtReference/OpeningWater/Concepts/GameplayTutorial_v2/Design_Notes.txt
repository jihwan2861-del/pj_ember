Project Ember 게임 튜토리얼 수정 시안 v2
날짜: 2026-10-19
제작: 내장 imagegen. 1·2번 그림 수정, 3번 기존 그림 재사용.
배치 검토용 설계이며 씬·런타임 코드 변경 없음.
16:9 /36×20.25칸 기준. 한 칸0.5U면 Orthographic Size5.0625.
그림은 개념 구도이며 실제 타일 수·이탈 포물선은 배치 단계에서 맞춘다.

사용자 누락 지적 반영
"X로 가연성 있는 물체 태우고 거기로 들어가는거 빠짐"
첫 신규 교육을 미점화 가연물에 X로 점화하면서 진입하는 동작으로 수정했다.
C로 미리 태워야만 하는 교육으로 바꾸지 않는다.
선행 스토리에서 방향키·Z를 소개한 뒤, 고정 가연물 X→이동 불꽃 X→C+방향키+Z 순서다.

01_IgniteAndEnter.png
- 마른 나뭇가지 묶음 하나를4~6칸 거리, X 범위8칸 안에 둔다.
- 가연물 방향을 맞추고 X: 대상 점화→그 안으로 이동→진입 상태.
- 목표를 붙잡은 상태에서 Z로 빠져나와 넓은 오른쪽 발판에 착지한다.
- 아래 안전 받침을 두고 실패 시 재시도할 수 있게 한다.
- 성공 판정: 해당 가연물의 실제 점화+진입+안전한 이탈/착지.
- 고정 물체로 X를 먼저 익히며 꽃이나 추가 공격을 섞지 않는다.

02_FlowerFireRide.png
- 첫 단계에서 익힌 X를 움직이는 불꽃에 적용한다.
- 먼저 C로 대형 태양꽃을 깨우고, 꽃은 정해둔 방향으로 불꽃을 발사한다.
- 불꽃이 플레이어에서3~5칸 거리, X8칸 범위 안에 있을 때 첫 슬로와 X 안내.
- 그 꽃 불꽃에 실제 X 탑승을 확인하면 기존 배속으로 복귀한다.
- Z로 오염 앞 넓은 발판에 이탈, 꽃 불꽃은 계속 날아가 꽃 전용 오염을 정화한다.
- 탄환이 소멸할 때 탑승자가 남으면 안전 하차 처리.
- 성공 판정: 실제 탑승+오염 정화+안전 착지.

03_IgnitionDash.png
- C→방향키+Z 짧은3~4칸 대시. 첫 회 충분한 안내 시간, 안전 받침.
- 오른쪽에서 안내를 줄이고 한 번 반복.
- X 대시나 추가 점프만으로 학습 완료하지 않고 C+Z 실제 대시와 착지 확인.
- v1의3번 그림과 동일하다.

현 코드와 설계의 차이 — 후속 구현 항목
- 현재 FindBurningFire/TryAbsorb는 이미 타는 대상만 고른다.
- 미점화 가연물 앞 X는 현재 대상 없는 대시로 이어진다.
- 따라서 X로 미점화 가연물을 점화하고 진입하는 동작은 앞으로 구현/복원해야 한다.
- 젖은 대상, 막힌 경로, 사거리 밖 대상은 별도 실패 처리 필요.
- 꽃탄환도 현재 탑승 대상이 아니며 이동 추종·소멸 전 안전 하차가 필요하다.
- C 링 안 X가 현재 불씨 사격 조준과 충돌하므로 튜토리얼 단계의 입력 우선순위 조정 필요.
- C링0.3초/배속/일시정지에 대응하는 첫 안내 대기·슬로 필요.
