# 오프닝 3컷 만화 시안

2026-10-20 사용자 요청에 따른 예시 이미지. 정상 태양에서 불씨 분리 → 산과 구름 사이 하강 → 원형 땅 꼭대기 착지/깨어남의3컷이다. 마지막 컷은 실제 원형 시작 구도로 이어지는 방향이다.

작은 불꽃은 팔다리가 없으며, 후반 태양꽃 반응에서 앰버가 되는 흐름을 유지한다. 원본 시안은 한 장짜리 3컷 이미지다. Storyscene에서는 복사본 `Assets/Ember/Art/Storybook/OpeningComic_ThreePanels_v1.png`를 전체 화면 UI로 사용하며 개별 패널 전환은 하지 않는다. 만화 표시와 페이드 시간은 `OpeningComicSequence` Inspector에서 조절한다. 생성 방식은 내장 image_gen이다.
