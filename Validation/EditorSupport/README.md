# 격리 검사용 생성 코드

실제 Unity 편집 메뉴에서 제거한 이전 씬·프리팹 생성 코드 8개다. 기존 검사에서 이 클래스를 호출하므로 소스를 보존한다.

이 폴더는 Assets 밖에 있다. 평상시 컴파일·메뉴 등록·에디터 시작 시 자동 설정 대상이 아니다. 기존 검사 실행 스크립트가 필요한 코드를 별도의 QA 프로젝트 Assets/Editor로 복사한다.

일반 편집에는 Level Workflow와 이미 만들어진 프리팹·Tile Palette를 사용한다. 이 폴더를 실제 프로젝트 Assets에 다시 복사하면 이전 생성 메뉴와 초기화 코드가 활성화되므로 일반 배치 용도로 사용하지 않는다.
