# Design

## Context

범위는 proposal.md를 따른다. 사용자가 레벨 타일과 방 구성을 직접 제작한다. 기존 플레이어·기믹·카메라는 재사용하며 보스 기능만 연결한다. 기존 방에는 재시작과 완료 경로가 있고 플레이어 ResetAt은 능력 상태를 해제한다. 일반 충돌체가 비활성화되는 능력도 있으므로 보스 위험은 일반 트리거에만 의존할 수 없다.

## Goals / Non-Goals

**Goals:**
- 임의로 저작된 보스 지형에 프리팹과 참조 설정으로 연결한다.
- 공격 예고와 위험 판정을 일치시키며 기존 재시작에 보스 상태를 함께 복구한다.
- 인스펙터에서 공격과 수위를 조정할 수 있도록 한다.

**Non-Goals:**
- 일반 방 목록·전환 관리자, 타일 생성 도구와 지형을 제작하지 않는다.
- 기존 플레이어 성능·조작, 카메라와 전체 스테이지 구조를 변경하지 않는다.

## Decisions

### 배치 가능한 보스 프리팹과 선택적 연결

보스 프리팹은 정령, 돌진 예고, 파도와 물 표현을 포함한다. 플레이어, 기존 방, 활동 경계, 보스 시작점, 수위와 승리 출구를 명시적으로 연결한다. 스테이지 전체 관리자를 만드는 대안은 사용자 레벨 제작 방식과 무관한 범위를 추가하므로 채택하지 않는다. game.unity의 타일과 카메라를 자동으로 수정하지 않는다.

진입은 지정한 시작 트리거 또는 명시적 시작 호출로 활성화한다. 연결 누락은 편집 단계에서 표시하고 필수 참조가 없으면 공격을 시작하지 않는다. 공격값과 경계는 직렬화 필드 및 기즈모로 확인 가능하게 한다.

### 기존 방의 재시작·완료를 소유자로 유지

기존 방이 플레이어 체크포인트 복귀를 담당하며 보스는 재시작 통지에 반응한다. 필요한 경우 기존 방에 선택적인 재시작·완료 알림을 추가한다. 보스 자체가 별도 플레이어 재시작을 병행하는 대안은 중복 복귀 위험 때문에 사용하지 않는다. 기존 체크포인트의 위치·기믹 초기화는 그대로 유지하고 보스 위치·수위·공격 순서만 함께 복구한다.

기본 보스 시작 상태로 복구하고 짧은 진입 유예를 제공한다. 출구 승리는 기존 완료 경로와 보스 정지·완료 표시를 연결한다. 완료 뒤 위험 요청을 무시하고 동시에 접수된 사망이 있다면 승리보다 먼저 처리한다. 기존 보스 없는 씬의 재시작과 완료는 유지한다.

### 한 공격 순서와 별도의 상승 물

진입 유예 → 추적 → 돌진 예고 → 돌진 → 회복 → 파도 예고 → 파도 횡단 → 회복 → 추적을 반복한다. 추적 몸체는 비위험이며 돌진 중에만 위험해진다. 예고 순간 방향·범위를 고정하고 지형·설정 경계를 반영한 실제 돌진 범위를 표시한다.

파도는 좌우 교대로 진행한다. 예고 당시 수위를 파도 바닥으로 고정하고 높이는 실측 이단 점프 높이를 초기값으로 설정한다. 파도는 활동 폭을 횡단하며 예고 뒤 높이나 방향을 바꾸지 않는다. 사용자에게 높은 회피 지형이 필요한 점을 배치 안내에 명시한다.

물은 게임 시간으로 지속 상승한다. 불꽃 조준의 시간 감속에 보스도 동일하게 반응한다. 돌진과 파도 위험 구간은 겹치지 않고 물만 병행한다. 무작위 공격은 재시도 예측 가능성을 낮추므로 처음에는 사용하지 않는다.

### 공간과 이동 경로에 의한 위험 판정

플레이어 몸체 크기와 이전·현재 위치를 사용해 물·파도·돌진 접촉을 검사한다. 트리거만 사용하는 대안은 능력 중 비활성 충돌체와 빠른 이동을 놓칠 수 있다. 위험 요청을 하나의 기존 재시작 경로로 합치며 예고·표현·판정 영역은 기즈모로 함께 확인한다.

### 기능 검증과 배치 안내

독립 검증용 최소 지형에서 실제 이동과 세 가지 패턴을 확인한다. 테스트 지형은 사용자 본편 레벨을 대신하지 않는다. 패턴 순서, 예고 고정, 양방향 파도, 시간 감속, 능력 중 접촉, 재시작 초기화와 승리 정지를 통합 검사한다. 보스 배치·출구 연결·조정값 안내와 검증 기록을 전달한다. 사용자 레벨 전체 완주를 구현 완료 조건으로 두지 않는다.

## Risks / Trade-offs

- 사용자 지형에 회피 지점이 없을 수 있음 → 예고 시간과 높은 거점 배치 기준을 문서화하고 조정값을 노출한다.
- 재시작 후 수위가 시작점보다 높음 → 시작 수위·유예를 조절 가능하게 하고 배치 안내 및 복구 검사로 확인한다.
- 위험 시각 표현과 판정 불일치 → 공간 판정 기즈모와 화면 캡처로 확인한다.
- 재시작 알림 추가가 기존 씬에 영향 → 선택적인 구독과 기존 씬 회귀 검사를 사용한다.

## Migration Plan

사용자가 제작한 씬과 타일을 보존한다. 새 프리팹·소스·안내만 추가하고 기존 방에는 필요한 선택적 연결만 수정한다. 운영 에디터와 충돌하지 않는 복제 프로젝트에서 컴파일·검증한다. 자동으로 game.unity에 보스를 배치하거나 빌드 설정을 변경하지 않는다. 되돌릴 때 이번 보스 파일과 선택적 연결만 제거한다.

## Open Questions

- 최종 정령·물·파도 아트는 추후 교체하며 최초 구현은 임시 표현을 사용한다.
- 공격 시간·속도·파도 높이·시작 수위는 검증 환경의 초기값을 제공하고 사용자가 만든 지형에 맞춰 조절한다.
