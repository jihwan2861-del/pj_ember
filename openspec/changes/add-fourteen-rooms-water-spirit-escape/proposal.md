# Proposal

## Why

사용자가 타일로 일반 방 14개와 보스 방 1개의 지형을 직접 제작한다. 이번 구현은 그 지형에 배치할 물의 정령과 세 가지 위험 패턴, 보스 재시작 및 출구 승리를 제공한다.

## What Changes

- 추적 → 범위·방향 예고 → 고정 방향 돌진을 구현한다.
- 좌우로 이동하는 이단 점프 높이 근처의 파도를 구현한다.
- 아래에서 차오르는 물로 위쪽 이동을 유도한다.
- 돌진과 파도는 교대로 실행하고 물은 함께 상승한다.
- 위험 접촉이나 R 재시작에서 기존 체크포인트 복귀와 함께 보스 위치·공격·파도·수위를 초기화한다.
- 지정한 출구 도착에서 승리하고 모든 보스 위험을 중단한다.
- 보스 프리팹과 연결 컴포넌트를 제공한다. 속도·예고 시간·파도 높이·물 상승 속도·활동 경계·출구·플레이어 참조를 인스펙터에서 설정할 수 있게 한다.
- 보스 기능은 독립적인 검증 환경에서 확인하고 사용자 지형에 배치하는 방법을 문서화한다.

일반 방과 보스 방의 타일·착지 지형·기믹 배치·카메라·방 순서는 사용자가 제작한다. 일반 방 14개와 보스 방 1개, 기본 약 36×20타일 화면은 레벨 계획의 배경이며 이번 구현의 제작·완주 검증 대상이 아니다.

## Capabilities

### New Capabilities

- `water-spirit-escape`: 조절 가능한 보스 추적·예고 돌진·양방향 파도·상승 물, 기존 재시작 연동 및 지정 출구 승리.

### Modified Capabilities

없음. 아직 등록된 기본 명세가 없다. 기존 플레이어와 기믹 동작은 유지한다.

## Impact

- 새 보스·파도·상승 물 컴포넌트, 배치 가능한 프리팹과 출구 연결.
- 기존 방 재시작·완료 경로에 필요한 최소한의 선택적 연동. 보스가 연결되지 않은 씬은 기존 동작을 유지한다.
- 보스 통합 검사와 배치·조정 안내. 최종 아트가 없으면 구분 가능한 임시 표현을 사용한다.
- 타일 자동 생성, 일반 방 제작, 보스 지형 제작, 전체 스테이지 진행 관리자, 카메라 변경, 플레이어 성능·조작 변경, 체력 전투와 빌드 설정 변경은 제외한다.
