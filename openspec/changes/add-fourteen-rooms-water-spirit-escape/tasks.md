# Tasks

2026-10-06: 사용자 요청으로 물 보스 구현을 모두 제거했다. 아래 계획은 참고용이며 현재 구현 완료 상태가 아니다. 다음 구현은 기능 하나씩 다시 정한다.

## 1. 보스 배치 기반과 재시작 연결

- [ ] 1.1 보스 프리팹과 플레이어·방·활동 경계·시작점·시작 트리거 설정을 구현한다. 참조 누락 시 공격하지 않고 기즈모로 경계를 확인할 수 있는지 검사한다.
- [ ] 1.2 기존 방 재시작에 보스 초기화 통지를 최소 변경으로 연결한다. R 및 위험 접촉에서 한 번만 복귀하고 보스 없는 기존 씬 동작이 유지되는 회귀 검사를 통과시킨다.
- [ ] 1.3 프리팹 배치와 필수 참조 설정 방법을 문서화한다. 독립 검증 환경에서 안내대로 연결해 시작 트리거 작동을 확인한다.

## 2. 물의 정령 공격과 상승 물

- [ ] 2.1 추적·돌진 예고·고정 방향 돌진·회복을 구현한다. 예고 후 재조준하지 않으며 표시 범위와 실제 위험 경로가 일치하는 검사를 통과시킨다.
- [ ] 2.2 현재 플레이어 이단 점프 높이를 측정해 파도 초기값을 정하고 양방향 파도·예고·교대 순서를 구현한다. 높이·방향 고정과 돌진/파도 비중첩 검사 및 실측 기록을 남긴다.
- [ ] 2.3 상승 물과 게임 시간 기준 공격 진행을 구현한다. 진입 유예, 조준 시간 감속, 재시작 시 보스 위치·파도·수위·공격 순서 초기화 검사를 통과시킨다.
- [ ] 2.4 몸체 및 이동 경로 기반 위험 판정을 구현한다. 일반 이동·흡수·빠른 이동에서 세 위험의 접촉이 기존 재시작으로 연결되는 검사를 통과시킨다.
- [ ] 2.5 속도·예고 시간·파도 높이·물 상승 속도·시작 수위를 인스펙터에 노출하고 조정 안내를 작성한다. 변경값이 실제 패턴에 반영되고 기즈모와 화면상 위험이 일치하는지 확인한다.

## 3. 출구 승리와 보스 기능 통합

- [ ] 3.1 지정한 출구에 보스 승리 연결과 완료 표시를 구현한다. 출구 도착 후 공격·파도·수위 상승 및 사망 처리가 멈추는 검사와 사망/출구 동시 요청 검사를 통과시킨다.
- [ ] 3.2 출구 연결·재시작·높은 회피 지형 배치 기준을 안내에 추가한다. 독립 검증 환경에서 문서대로 출구를 연결해 완료와 재시작을 확인한다.
- [ ] 3.3 복제 프로젝트에서 관련 기존 회귀 검사와 보스 통합 검사를 실행한다. 컴파일 오류 없는 결과와 테스트 XML을 남기고 사용자 씬·타일·카메라·빌드 설정이 보존되었는지 diff로 확인한다.
- [ ] 3.4 독립 검증용 최소 지형에서 실제 입력으로 추적 회피·돌진 회피·양방향 파도 회피·상승 물 탈출·출구 승리를 확인한다. 재시작 기록과 화면 캡처를 전달하며 검증 지형이 본편 제작물과 구별되는지 확인한다.

## Workflow follow-up

- 사용자는 일반 방 14개와 보스 방 1개의 타일·기믹·카메라·연결을 직접 제작한다.
- 사용자 지형에 보스를 배치한 이후 공격 시간과 수위 속도를 실제 플레이로 조절한다. 본편 전체 완주는 이번 보스 기능 구현의 완료 조건이 아니다.
