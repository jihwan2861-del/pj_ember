# Design

## Context

FlammableTile은 TryIgnite에서 점화·번짐을 시작하고 ResetFire에서 초기 불을 다시 점화한다. 따라서 ResetFire를 소화에 재사용할 수 없다. FireStateChanged는 AllTorchesDoor가 구독하며 기존 onFireReset에는 리스폰용 연결이 있을 수 있다. WaterWave는 실제 PolygonCollider2D와 Rigidbody2D를 사용하고 정지 시 콜라이더를 끄며 정령마다 재사용한다. 불 이동과 로프는 IsBurning 또는 IsAvailable을 검사한다. MapReset은 파도를 정리한 뒤 불의 초기 상태를 복원한다.

## Goals / Non-Goals

**Goals:** 점화 진입점을 한 곳에서 차단하고 실제 충돌 모양·불 상태·리스폰 상태를 일치시킨다. 요구사항은 specs/water-fire-interaction/spec.md를 따른다.

**Non-Goals:** 불 상태를 별도 시스템으로 전면 교체하거나 기존 리스폰 이벤트와 보스 공격 상태를 재설계하지 않는다.

## Decisions

1. FlammableTile에 초기 설정을 바꾸지 않는 Extinguish와 물 접촉 상태를 추가한다. 소화는 예약 번짐을 취소하고 외형·이펙트·IsBurning을 갱신하며 실제 상태 전환 때만 FireStateChanged를 알린다. 기존 onFireReset은 리스폰 전용으로 유지한다. ResetFire 호출 방식은 초기 불 재점화와 이벤트 의미 때문에 제외한다.
2. 공통 WaterContact 컴포넌트는 물의 실제 Collider2D를 사용한다. 보스 WaterWave 프리팹에 연결하고 일반 물 영역에도 동일 컴포넌트를 배치할 수 있게 한다. 피해용 RoomHazard와 독립적이므로 Deadly=false인 파도도 소화한다. 화면 표시 영역이나 보스 돌진 히트박스에는 연결하지 않는다.
3. 물 콜라이더와 대상 콜라이더의 접촉 쌍을 중복 없이 추적하고 부모의 FlammableTile로 해석한다. 대상은 활성 접촉 원천을 집합으로 관리한다. 단일 bool 방식은 중첩 물에서 조기 해제가 발생하므로 제외한다. 각 물리 갱신의 실제 겹침 조회로 최초·유지·종료를 동기화하여 정적 대상, 비활성화, 재활성화에서도 누락되지 않게 한다. 조회 버퍼 포화 시 확장하며 전체 씬 오브젝트를 매 프레임 검색하지 않는다.
4. TryIgnite에서 물 접촉을 확인해 수동 점화·투사체·번짐의 공통 차단점을 만든다. 마지막 접촉 종료는 허용 상태만 변경하며 자동 점화하지 않는다. 전용 소화 API와 점화 차단은 여러 번 호출해도 중복 이벤트를 내지 않는다.
5. WaterWave의 Launch/Play는 물 접촉을 활성화하고 Stop/Reset/OnDisable/삭제는 접촉을 명시 해제한다. OnTriggerExit만 기다리는 방식은 콜라이더 비활성화와 풀 재사용에서 상태가 남을 수 있어 제외한다.
6. MapReset에서 이전 파도 접촉을 해제하고 초기 불을 복원한 뒤 Physics2D.SyncTransforms와 물 접촉 재동기화로 상시 물의 차단을 복구한다. 사망 연출 중 파도 재개 보류를 유지한다.
7. 현재 불 이동의 무효 대상 중단과 로프의 이용 불가 해제 경로를 재사용한다. 이용 중인 일반 불에서 꺼진 뒤에도 머무르는 경로가 있으면 같은 상태 변경 신호로 기존 탈출/해제 경로를 연결한다. 새로운 사망이나 추진 효과는 만들지 않는다.

## Risks / Trade-offs

- [동일 물의 복수 콜라이더·복수 대상 콜라이더] → 접촉 쌍과 원천 집합을 구분하고 부분 이탈 검사를 추가한다.
- [리스폰 직후 상시 물과 초기 불의 충돌] → 초기 불 복원 후 실제 접촉을 재동기화한다.
- [기존 퍼즐 이벤트가 리스폰과 소화를 혼동함] → onFireReset 의미를 보존하고 상태 구독자의 동작을 회귀 검사한다.
- [빠른 파도의 누락 접촉] → 실제 파도 이동·물리 갱신에서 검증하고 필요 시 이동 구간의 동일 충돌 모양 조회를 보완한다.

## Migration Plan

새 물 컴포넌트와 소화 API를 추가하고 기존 WaterWave 프리팹 GUID·애니메이션·피해 설정을 보존하며 연결한다. 일반 물 배치용 설정 문서를 작성하되 본편 지형은 자동 편집하지 않는다. 별도 Unity QA 프로젝트에서 물리·리스폰·기존 공격 검사를 실행한다. 되돌릴 때는 추가 물 컴포넌트 연결과 런타임 변경만 제거하며 초기 불 설정을 유지한다.
