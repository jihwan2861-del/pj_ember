# Design

## Context

동기는 proposal.md, 동작 계약은 specs/burning-rope-swing/spec.md에 정리했다. 현재 FlamePlayerController는 Free/Travelling/Anchored 등을 관리한다. BeginFireTravel은 속도를 0으로 바꾸고 FixedUpdate의 Travelling은 움직이는 AnchorPosition을 목표로 이동한다. Anchored는 속도를 0으로 고정하고 LaunchFromFire는 지정 방향에 launchSpeed를 적용한다. PlayerAbilityInputRouter는 IsInsideFire에서 Z와 X를 분기한다. FlammableTile은 sealed 클래스이며 선택적 absorbPoint와 점화 이벤트를 제공한다. Validation/Movement에는 실제 물리 스텝을 사용하는 격리 회귀 검사와 스프링·이동 플랫폼 검사가 있다.

이 변경은 이동 상태, 점화, 입력, 표시를 함께 다루므로 별도 설계가 필요하다. 과거 20분 기획의 로프 제외 범위는 이번 추가 요청으로 확장하되 전체 방 구성을 다시 설계하지 않는다.

## Goals / Non-Goals

**Goals:**
- 로프 시뮬레이션과 플레이어 상태 전환의 책임을 분리하고 물리 계산과 시각적 휘어짐을 일치시키기.
- 흡수 이동 속도와 진입 운동량을 분리해 기존 횃불 동작을 보존하기.
- 연결 속도, 박차기, 감쇠, 공중 조절을 인스펙터에서 조정하고 반복 검증하기.

**Non-Goals:**
- 모든 가연물을 새 상속 체계로 재작성하거나 다수 관절의 자유 로프 물리를 도입하지 않는다.
- 기본 진행에 고급 기술을 강제하는 전체 레벨 제작은 포함하지 않는다.

## Decisions

### 로프 끝에 기존 가연물 연결
새 BurningRope 컴포넌트가 고정점, 길이, 각도, 각속도와 끝 지점을 관리하고 끝의 FlammableTile을 기존 탐색에 연결한다. 몸통은 흡수 탐색용 가연물 콜라이더를 갖지 않는다. FlammableTile 상속 대신 조합을 사용한다. 점화 상태는 기존 이벤트로 표시와 연결한다.

### 별도 부착 상태와 일관된 스텝 순서
플레이어에 로프 부착 상태를 추가한다. 입력 라우터의 X/Z 전달은 유지하고 컨트롤러에서 대상 종류로 분기한다. 로프는 FixedUpdate에서 중력과 좌우 힘을 계산하며 플레이어 위치는 그 스텝의 끝 위치를 따른다. 실행 순서 또는 명시적 스텝 호출 중 하나로 순서를 보장해 한 프레임 지연을 방지한다. 기존 Anchored의 정지 규칙을 수정하여 전체 횃불에 적용하는 방안은 제외한다.

### 진입 운동량과 흡수 속도 분리
X가 유효한 로프 대상을 선택한 순간 플레이어의 물리 속도를 저장한다. 부착 시 단위 접선 t와 길이 L로 dot(v,t)/L을 각속도에 반영한다. 움직이던 로프의 각속도와의 결합은 조정 가능한 질량/전달 계수로 처리하며 같은 속도를 두 번 더하지 않는다. 실패·취소·초기화 시 저장값을 폐기한다.

초기 조정 가정은 로프 흡수 이동 속도도 저장 속도를 참고해 기존 흡수 속도와 안전 상한 사이에서 설정하는 것이다. 저장 운동량은 이동 속도와 독립적이다. 움직이는 목표를 계속 갱신하고 접근 속도가 목표를 따라잡을 수 있도록 보장한다. 실제 수치는 연속 연결 테스트에서 결정하며 현재 설정을 확정값으로 취급하지 않는다.

### 일정 길이 진자와 별도 표시
고정 길이 진자를 사용해 중력, 입력 토크, 작은 감쇠와 안전 속도 상한을 계산한다. LineRenderer의 중간 점에 제한된 시각적 지연과 휘어짐을 적용하되 양 끝은 실제 위치에 고정한다. 다중 Rigidbody2D 관절 체인은 큰 처짐과 수치 흔들림으로 타이밍 예측을 어렵게 하므로 초기 구현에서 사용하지 않는다.

기본 배치는 정지 상태로 시작하고 초기 각도/각속도는 설정 가능하게 둔다. 이는 미논의 세부에 대한 초기 가정이며 사용자가 시작 움직임을 별도로 확정한 것은 아니다. 재시작 시 초기값으로 되돌린다.

### 박차기와 반작용
끝 속도 v에 normalize(v) * kickBoost를 더해 이탈시킨다. 유효 속도가 없는 경우 추가 추진력 없이 중력으로 떨어진다. 반대 충격은 별도 반동 계수로 줄 각속도에 적용한다. 반동은 역방향 속도 변화이며 기존 기세에 따라 반드시 즉시 반대로 움직일 필요는 없다. 방향키로 이탈 방향을 대체하지 않는다. 무제한 속도 폭증을 막는 상한은 일반 걷기 속도보다 충분히 높게 조정한다.

### 공중 운동량 구간
로프 이탈 후 전용 운동량 유지 모드에서 수평 입력을 가속도로 적용하고 기존 moveSpeed 즉시 제한과 강한 감속을 피한다. 중력은 계속 적용한다. 착지·일반 횃불 진입·새 발사·스프링·대시·재시작 등 다른 이동 원인이 속도를 소유할 때 모드를 종료하고 해당 동작의 기존 규칙을 사용한다. 점프 해제에 의한 상승 절단은 로프 박차기에 적용하지 않는다. 능력 회복은 기존 불 진입 정책을 재사용하며 새로운 무제한 자원 규칙은 만들지 않는다.

### 충돌과 수명
흡수 경로의 기존 캐스트 검사를 재사용한다. 부착 중 줄 끝 이동도 플레이어 크기로 검사하고 벽에 막히면 마지막 안전 위치에서 회전을 멈춘다. 줄 몸통은 초기 구현에서 지형과 충돌하지 않으므로 제작 시 장애물과 겹치지 않는 회전 공간을 확보한다. 이탈은 기존 안전 출구 검사 취지를 재사용해 관통을 막는다. 대상 비활성화·불 초기화는 안전 해제, 제어 잠금은 입력과 부착 이동 정지, 재시작은 참조·저장 속도·표시·콜라이더 상태까지 초기화한다.

## Risks / Trade-offs

- 흡수 구간에서 감속되어 보임 → 저장 속도와 접근 속도를 따로 검증하고 두 로프 연결 장면에서 조정한다.
- 빠른 회전의 관통과 목표 추격 실패 → 끝 이동 캐스트, 속도 상한 및 움직이는 목표 도착 검사를 둔다.
- 로프 반동과 다음 진입이 중복 가속 → 진입값은 한 번만 소비하고 연속 연결 검사에서 상한을 확인한다.
- 시각적 휘어짐이 실제 경로와 달라짐 → 끝은 물리에 고정하고 중간 편차만 작게 제한한다.
- 기존 자유 이동 감속과 충돌 → 전용 모드의 종료 조건과 기존 이동 회귀 검사를 함께 검증한다.

## Migration Plan

새 로프 컴포넌트와 플레이어 분기를 추가한 뒤 별도 최소 검증 구간에 적용한다. 기존 2.unity 방 배치를 일괄 변경하지 않는다. 초기값과 세팅 안내를 문서화하고 기존 이동 회귀와 실제 플레이를 확인한다. 되돌릴 때 새 로프 배치와 컴포넌트를 제거하고 로프 관련 플레이어 분기만 복원한다. 기존 가연물 데이터의 마이그레이션은 필요하지 않다.

## Open Questions

- 흡수 접근 속도, 입력 힘, 감쇠, 박차기 및 반동 계수, 공중 조절량, 안전 상한의 최종 수치는 플레이 검증으로 결정한다.
- 불꽃/줄의 표현 강도는 비교 이미지 2번을 기준으로 실제 화면 크기에서 조정한다.
