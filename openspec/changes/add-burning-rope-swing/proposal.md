# Proposal

## Why

횃불에서 발사하는 이동에 진입 각도와 이탈 타이밍을 활용하는 로프 스윙을 더한다. 여러 로프를 연속으로 타며 기세를 이어가는 이동과 숙련자가 발견할 수 있는 빠른 경로를 만들기 위함이다.

## What Changes

- 불붙은 로프 끝 하나를 X 흡수 대상으로 제공한다. 줄 중간은 흡수 대상이 아니다.
- 진입 직전 속도를 스윙에 전달하고 좌우 입력으로 반동을 키운다.
- Z로 이탈할 때 스윙 속도를 이어받고 같은 진행 방향으로 추가 추진력을 받는다. 줄에는 반대 방향 반동이 남는다.
- 이탈 후 공중에서는 기세를 유지하며 방향키로 궤도를 조금씩 조절한다.
- 줄은 길이를 유지하는 진자 이동에 작은 휘어짐과 지연을 표현한다. 선택한 비교 이미지 2번의 느낌을 기준으로 한다.
- 기본 불붙은 물체의 X 흡수·방향 지정 Z 발사와 기존 Z/X/C 조작을 유지한다.
- 연속 로프 연결을 검증할 별도 최소 테스트 구간과 설정 안내를 제공한다. 전체 스테이지 제작, 발사형 그래플, 줄 길이 조절, 줄 소진 시간은 제외한다.

## Capabilities

### New Capabilities

- `burning-rope-swing`: 불붙은 로프 끝 흡수, 운동량을 전달하는 스윙과 이탈, 반동 표현 및 연속 연결.

### Modified Capabilities

없음. 현재 등록된 기존 명세가 없다.

## Impact

- `Assets/EmberPrototype/Runtime/FlamePlayerController.cs`의 흡수 이동·고정 상태·발사·공중 제어 및 초기화 경로.
- `PlayerAbilityInputRouter.cs`의 물체별 X/Z 분기, `FlammableTile.cs`의 점화 및 흡수 지점 연동.
- 새 로프 동작/표현 컴포넌트와 최소 검증 구간, `Validation/Movement`의 이동 회귀 테스트 및 설정 문서.
- 외부 패키지 추가는 계획하지 않는다. 실제 흡수 이동 속도와 추진력 수치는 검증 후 조정하며, 기존 물체의 속도를 일괄 변경하지 않는다.
