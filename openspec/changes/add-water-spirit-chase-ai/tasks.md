# Tasks

## 1. AI 소유권과 모드 기반

- [x] 1.1 기존 정령 API·직렬화 필드를 유지하며 AI의 공격 소유권과 행동 모드 계약을 추가한다. AI 연결 중 자동 발사가 중복되지 않고 AI 없는 기존 자동·수동 동작이 유지되는 Unity 검사를 통과시킨다.
- [x] 1.2 명시적인 플레이어·직교 카메라·초기 모드 참조 검사와 실행 중 참조 소실 처리를 구현한다. 참조 누락 및 소실 시 진단과 이동·공격 중단을 검증하고 연결 요구사항을 안내 문서에 기록한다.

## 2. 화면 기준 추적과 고정 파도 공격

- [x] 2.1 기본 추격 모드에 화면 왼쪽 목표·플레이어 몸체 중심 높이·설정 속도 접근·추적 시간 및 위치 도달 조건을 구현한다. 플레이어 높이와 카메라 위치·화면 비율 변화에 목표가 반응하고 추적 중 발사하지 않는 검사를 통과시킨다.
- [x] 2.2 파도 설정의 읽기 및 고정된 월드 공격 정보 전달을 추가하고 예고 표시를 구현한다. 플레이어 중심과 파도 중심 높이 일치, 루트 스케일 반영, 예고 후 카메라·플레이어 이동에도 경로 불변을 실제 생성 파도와 비교하는 검사를 통과시킨다.
- [x] 2.3 추적·예고·발사·회복을 연결하고 애니메이션 발사 시점 및 단일 파도 완료를 사용한다. 한 번 발사·자동 반복 없음·회복 완료 조건·일시정지 및 시간 감속에 대한 Unity 검사를 통과시킨다.
- [x] 2.4 추적 속도·화면 여백·추적 2초·예고 0.7초·회복 설정을 편집 화면에 노출한다. 기본 모드 배치와 파도 높이·거리 조정 및 회피 발판 안내를 작성하고 독립 검증 씬에서 문서대로 연결해 기본 공격을 확인한다.

## 3. 외부 모드 요청과 복구

- [x] 3.1 외부 모드 요청·유효성 검사·즉시 또는 보류 전환을 구현한다. 테스트 전용 두 번째 행동으로 추적 중 전환, 예고·파도 중 전환 보류, 마지막 요청 우선, 동일 모드 요청 및 무효 요청 처리를 검증한다. 조건 소유자의 API 호출 예시와 후속 모드 작성 계약을 안내한다.
- [x] 3.2 기존 MapReset 복구·리스폰 완료 경로와 AI 상태를 연결한다. 사망 시 예고·파도 정리, 초기 모드 복구, 보류 요청 취소, 사망 연출 동안 정지 및 비활성화·재활성화 검사를 통과시킨다.
