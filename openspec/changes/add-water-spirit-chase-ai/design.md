# Design

## Context

동기와 범위는 proposal.md를 따른다. `WaterSpirit`는 애니메이션, 이동 속도 전달, 단일 재사용 파도 및 사망 보류를 소유한다. `Attack()`은 이전 파도가 이동 중이면 요청을 무시한다. `WaterWave.Launch()`는 방향을 받고 자동 시작·반복을 끈다. 파도 높이와 거리 설정은 현재 비공개이며 발사점은 정령 로컬 위치에서 계산한다. 따라서 AI가 예고한 월드 경로를 발사 시점까지 보존할 최소한의 명시적 전달 경로가 필요하다.

`MapReset`은 정령과 파도의 초기화 및 리스폰 완료 통지를 제공한다. 기존 카메라는 직교 방 카메라이며 실제 렌더 카메라에서 화면 경계를 읽을 수 있다. 검증은 복제 프로젝트의 Unity 테스트와 `Validation/WaterSpirit`, `Validation/Wave` 관례를 사용한다. 이전 14개 방 전체 보스 계획은 참고용이며 이 변경의 구현 기준이 아니다.

## Goals / Non-Goals

**Goals:** AI의 상태·모드 전환 소유자를 하나로 두고, 기존 정령의 표현·발사를 재사용하며 이후 모드 추가가 기본 추격 코드 수정에 의존하지 않게 한다.

**Non-Goals:** 범용 행동 트리·전역 보스 관리자·새 패키지를 만들지 않는다. 상승 추격 자리표시자를 실제 패턴처럼 실행하지 않는다. 특정 레벨의 조건이나 진행 상태를 정령 내부에 하드코딩하지 않는다.

## Decisions

### AI와 정령 실행 기능을 분리

`WaterSpiritAI`가 추적·예고·발사·회복 상태와 현재/보류 모드를 소유한다. `WaterSpirit`는 Animator, 실제 이동 및 발사·중단을 담당한다. 유효한 AI가 연결된 동안 기존 `autoAttack` 타이머는 실행하지 않고 AI가 공격 요청을 소유한다. AI를 제거하거나 의도적으로 끄면 기존 설정을 복구한다. 참조 오류로 AI가 활성화되지 못한 경우에는 자동 발사로 우회하지 않는다.

모드 전체를 기존 정령 클래스의 분기문에 넣는 대안은 후속 상승 추격의 수정 범위를 키우므로 채택하지 않는다. 기존 직렬화 필드·공개 API를 보존하고 필요한 설정값의 읽기 및 고정 발사 정보를 받는 기능만 추가한다.

### 모드별 작은 행동 컴포넌트

공통 행동 계약 `WaterSpiritBehavior`와 기본 구현 `SideChaseBehavior`를 둔다. 모드는 활성화 시 초기화, 추적 목표 계산, 준비 조건, 공격 선택·시간 설정, 종료 시 정리를 제공한다. AI의 공통 상태 진행·전환 안전성과 정령 실행 기능은 모드가 복제하지 않는다.

외부 진입점은 정령에 연결된 행동 컴포넌트를 받는 `RequestBehavior(...)` 형태로 둔다. 스위치·구역·높이 조건은 이 API를 호출하는 외부 소유자의 책임이다. 명시적 등록 목록 또는 같은 정령의 연결된 행동으로 유효성을 확인하고 실패 결과를 반환한다. 실제 상승 추격 구현은 이번 변경에 추가하지 않는다. 테스트 전용 행동으로 전환 계약을 확인한다.

열거형에 미구현 상승 모드를 넣는 대안은 선택 가능한 빈 동작을 만들고 매번 분기를 수정하게 하므로 피한다. ScriptableObject 행동 트리나 서비스 등록기는 현재 규모에 필요하지 않다.

### 화면 기준 추적과 월드 경로 고정

플레이어와 카메라 참조는 인스펙터에서 명시적으로 연결한다. 화면 왼쪽 위치는 지정 직교 카메라의 뷰포트에서 정령 평면의 월드 좌표로 변환하고 설정 여백을 더한다. 플레이어 높이는 몸체 경계 중심을 사용한다. 프레임마다 새 이동 목표를 계산하되 설정 속도로 접근하여 카메라 이동·흔들림 때 순간이동하지 않는다. 추적은 최소 2초 진행하고 왼쪽 목표에 허용 오차 내로 도달한 뒤 예고한다.

예고 시작 시 발사 시작점, 방향, 월드 높이·폭, 이동 거리를 한 공격 정보로 고정한다. 파도 바닥 높이는 플레이어 몸체 중심 높이에서 파도의 실제 월드 높이 절반을 뺀 값이다. 수평 시작점은 현재 정령의 발사 마커이며 오른쪽 방향을 사용한다. 파도 크기는 루트 스케일을 반영하고 실제 발사에도 같은 값을 적용한다.

별도의 간단한 위험 띠 또는 외곽선으로 고정한 파도 횡단 영역을 표시한다. 파도가 이동할 거리와 형태의 외접 영역을 쓰며 지형을 통과하는 기존 파도 성질도 안내한다. 예고 뒤에는 카메라·플레이어를 다시 읽어 경로를 바꾸지 않는다. 발사점이 정령에서 조금 떨어져 보일 수 있으므로 추적 시 정령·발사 마커를 높이에 맞추고 월드 발사 위치를 기즈모로 표시한다.

카메라 전체를 수정하거나 방 경계에 고정하는 대안은 합의한 화면 기준 추격과 다르므로 사용하지 않는다. 파도의 기존 이동 거리 설정을 기본으로 사용하고 예고에서 실제 도달 범위를 정확히 보여준다.

### 상태 진행과 전환 시점

추적 → 예고 → 발사 → 회복 → 추적을 반복한다. Move는 실제 이동 중, Idle은 예고·회복, Attack은 발사 단계에서 재생한다. 0.7초 예고는 기존 0.25초 공격 애니메이션 발사 지연과 별도다. 회복 완료 조건은 공격 애니메이션 종료, 파도 이동 종료, 설정 회복 시간 충족이다. 초기 회복 시간은 0.5초로 제안하고 인스펙터에서 조정한다.

추적 중 요청은 다음 AI 갱신에서 적용한다. 예고부터 회복 완료까지 요청을 한 슬롯에 보류하고 마지막 유효 요청을 사용한다. 현재 모드 재요청은 상태를 재시작하지 않고 보류 요청만 취소한다. 전환 때 이전 모드를 종료하고 예고·이동 명령을 정리한 뒤 새 모드의 추적 상태와 타이머를 시작한다. 무효 요청은 기존 보류 요청도 변경하지 않는다.

즉시 강제 전환은 이미 예고한 공격을 바꾸므로 제공하지 않는다. 긴 거리 파도로 전환이 늦어지는 것은 현재 공격 완료 정책의 결과이며 거리·속도 튜닝과 함께 안내한다.

### 재시작과 중단을 우선 처리

기존 `MapReset` 통지에서 AI 초기화도 같은 정령의 복구 흐름으로 전달한다. 사망 보류 시 AI·정령·파도·예고를 함께 정지하고 초기 모드 및 시작 위치를 복구한다. 리스폰 완료 후 초기 추적부터 재개한다. 요청 중복으로 별도의 플레이어 리스폰 경로를 만들지 않는다. 비활성화는 보류된 요청과 예고를 정리하며 재활성화는 초기 모드에서 시작한다. 대상이나 카메라가 실행 중 사라져도 새 발사를 중단하고 진단한다.

## Risks / Trade-offs

- 높이가 큰 파도는 점프만으로 피하기 어려움 → 파도 높이·예고 시간을 노출하고 실제 사용자 발판에서 상향 이동 회피를 확인한다.
- 카메라 방 전환으로 왼쪽 목표가 크게 이동함 → 속도 제한과 발사 위치 도달 조건을 사용하고 예고 이후 월드 경로를 고정한다.
- 기존 자동 발사와 AI가 동시에 공격함 → 공격 소유권을 단일화하고 AI 없는 기존 프리팹 회귀 검사를 둔다.
- 파도 크기·속도가 편집 중 바뀌어 예고와 달라짐 → 공격 정보 스냅샷을 실제 생성된 파도에 동일하게 적용한다.
- 화면 전체보다 짧은 기존 파도 거리 → 실제 위험 범위만 표시하고 거리 튜닝 방법을 전달한다.
- 사용자 지형에서 안전 경로 부재 → 자동 지형 생성 대신 회피 발판 및 파도 배치 기준을 안내한다.

## Migration Plan

새 AI·기본 모드·예고 표현을 기존 정령 프리팹에 연결하되 사용자 수정값과 애니메이션 GUID를 보존한다. 기존 생성 메뉴는 이미 있는 프리팹을 덮어쓰지 않으므로 별도의 명시적 AI 연결 메뉴 또는 안전한 프리팹 편집 절차를 제공한다. 사용자 씬에는 자동 배치하지 않고 플레이어·카메라 참조를 연결하는 안내를 제공한다.

복제 프로젝트에서 컴파일 및 기본 패턴·전환·복구와 기존 테스트를 실행한다. 되돌릴 때 새 AI 연결을 제거하면 기존 정령 실행 기능을 사용할 수 있어야 한다. 외부 조건의 실제 상승 추격 연결은 후속 변경에서 추가한다.

## Open Questions

- 추적 속도·여백·회복 시간의 최종 수치는 사용자 지형 플레이로 조정한다.
- 상승 추격의 구체적인 이동·공격 및 전환 조건은 후속 설계 대상이다. 이번 완료 조건에는 포함하지 않는다.
