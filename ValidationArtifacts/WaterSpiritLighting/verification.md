# 물의 정령 푸른 2D 조명

2026-10-07 Unity 6000.5.2f1 격리 QA 프로젝트에서 관련 검사 12개 모두 통과.

WaterSpirit에 자식 Point Light를 연결했다. 기본 색상 RGB=(0.15,0.55,1), 밝기 0.8, 외부 반경 2.5, 내부 반경 0.3이다. 색상·밝기·반경은 Water Spirit 컴포넌트에서 조절한다. 자식 조명이므로 이동을 따라오고 컴포넌트 비활성화 시 조명도 비활성화한다.

Native Unity 검사에서 조명 생성, 푸른색 설정, 밝기·반경 및 로컬 위치를 확인했고 기존 돌진·잔상·파도 검사도 통과했다. 본편 game 씬에 Sprite-Lit 머티리얼이 사용된 것을 확인했다. 본편 조명의 체감 밝기와 레벨 배경 대비는 플레이하며 조절한다.

결과: UnityResults.xml, unity.log.
