# 물의 정령 AI 검증

2026-10-07, Unity 6000.5.2f1 복제 프로젝트에서 실제 플레이 모드 진입·종료를 포함한 EditMode 실행 검사 17개가 통과했다. `UnityResults.xml`: Passed, total 17, passed 17, failed 0. `unity.log`에는 새 C# 컴파일 오류가 없고 실행 종료 코드는 0이다.

## 검증 범위

- 새 AI 검사 11개: 화면/플레이어 추적과 설정 기본값, 예고와 실제 파도의 월드 영역·루트 스케일 일치, 예고 뒤 플레이어/카메라/템플릿 설정 변경에도 공격 스냅샷 보존, 단일 발사 및 회복 완료.
- 초기 모드 요청, 추적 중 전환, 예고·파도 중 보류, 마지막 요청 우선, 현재 모드 재요청의 보류 취소와 타이머 보존, 무효·다른 정령 모드 거부.
- 필수 참조 누락과 카메라/플레이어 소실 시 정지, 자동 발사로 우회하지 않음, AI 비활성화 후 기존 자동 발사 복구.
- MapReset 기반 초기 모드·타이머 복구와 공격/파도/보류 요청 취소, 사망 보류와 완료 후 재개, 비활성화·재활성화 정리.
- 일시정지 및 시간 감속에서 예고 타이머 진행, Animator 및 실제 Rigidbody2D 파도 정지.
- 프리팹 연결 도구 중복 실행 시 컴포넌트 중복 없음, 기존 Animator·공격 설정 보존.
- 기존 정령 검사 3개 및 파도 검사 3개 회귀 통과. 기존 정령 검사는 AI를 비활성화하여 이전 수동 실행 경로를 검증했다.
