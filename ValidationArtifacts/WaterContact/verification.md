# 물 접촉 소화 검증

2026-10-07 Unity 6000.5.2f1의 별도 QA 프로젝트에서 소화·접촉·공격 20개와 불 이동·로프 회귀 20개, 총 40개 검사가 모두 통과했다.

## 결과

- UnityResults.xml: 새 소화 검사 8개와 기존 정령·파도 검사 12개, 20/20 통과.
- MovementResults.xml: 기존 불 이동·로프 검사 20/20 통과.
- unity.log, movement.log: 실제 Unity 실행·컴파일·테스트 로그.
- 01-burning.png, 02-extinguished.png: 소화 전후 외형 확인.

## 보존과 제한

본편 game.unity는 이번 구현에서 편집하지 않았으며 구현 시작 시 확인한 SHA256 E9F076D176DAB339FB9568660B924F1CA2F9C0C828788A3EC47131A80B7EEFDF를 유지한다. 이전 조사에서 보존한 지형·설정 기준과 비교하면 game.unity의 기존 사용자 변경만 남아 있고 추가 차이는 없다. WaterWave.prefab.meta 해시 EF3FB069A1E8D174AEA3F69AD937D0EEE90CCED4507CF6EEC43C8C9D0B28EFE6를 유지하며 프리팹에는 WaterContact 연결만 추가했다. 기존 초기 불 플래그와 리스폰 이벤트 의미를 보존했다.

일반 물은 Collider2D와 WaterContact를 사용자가 레벨에 배치한다. 보스 돌진 몸체·예고 표시에는 물 판정을 추가하지 않았다. 상승하는 물 연출 및 실제 레벨 난이도는 이번 범위가 아니다. 소화 검사 장면은 격리된 QA 환경이며 본편 전체 레벨 완주를 검증하지 않는다.

재실행: Validation/WaterContact/Run-Validation.ps1은 독립 복제 프로젝트에서 동일한 관련 검사 집합을 실행한다.
