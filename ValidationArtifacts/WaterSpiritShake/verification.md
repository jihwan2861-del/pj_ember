# 범위 밖 돌진과 파도 발사 쉐이킹 검증

2026-10-07 Unity 6000.5.2f1 별도 QA 프로젝트: 11개 테스트 모두 통과.

기존 추적·돌진·화면 제한·리스폰·정령/파도 회귀 검사에 다음 검사를 추가했다.

- 플레이어가 예고 범위 밖에 있고 카메라 위치 보정이 발생해도 예고가 유지되고 고정 방향으로 돌진한다.
- 파도 발사 전에는 쉐이킹을 요청하지 않는다. 실제 발사 시 0.1초, 강도 0.06을 요청하며 두 번의 발사를 각각 확인했다.

쉐이킹 요청 검사는 게임의 CelesteRoomCamera 컴포넌트를 사용했다. 본편 레벨에서 체감 강도는 Water Spirit의 Wave Shake Duration/Magnitude로 조정한다.

실행 결과는 UnityResults.xml과 unity.log에 기록했다.
