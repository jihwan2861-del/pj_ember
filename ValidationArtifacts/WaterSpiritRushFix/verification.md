# 돌진 즉시 취소 버그 조사

2026-10-07, Unity 6000.5.2f1.

증상: 위험 범위가 표시되지만 정령이 돌진하지 않는다는 사용자 보고.

코드에서는 화면 안으로 위치를 보정할 때 가로·세로 구분 없이 Rushing을 Tracking으로 바꾸고 있었다. 돌진 중 화면 상단에서 카메라가 0.03유닛 세로 보정을 유발하는 재현 검사를 추가했다.

수정 전: Before.xml, 재현 검사 1개 실패. 기대 Rushing, 실제 Tracking.
수정 후: UnityResults.xml, 관련 검사 12개 모두 통과. 동일 세로 보정 상황에서 Rushing 유지 및 실제 수평 이동 거리를 검증했다.

수정: 세로 화면 보정은 수평 돌진을 중단하지 않는다. 가로 화면 경계 보정 시에는 기존 화면 내부 제한을 유지하며 돌진을 끝낸다. 예고가 끝난 프레임부터 돌진 속도를 제공해 빈 이동 프레임도 제거했다.

검증은 별도 QA 프로젝트에서 수행했다. 본편 game.unity는 수정하지 않았으며 이번 조사 전·후 SHA256이 같다: E9F076D176DAB339FB9568660B924F1CA2F9C0C828788A3EC47131A80B7EEFDF.
