# 물의 정령 파도 탑승 추적 검증

2026-10-07 Unity 6000.5.2f1의 별도 QA 프로젝트에서 실제 플레이 모드로 9개 테스트를 실행했고 모두 통과했다.

- 위험 표시 없는 일반 파도 발사와 공격 중 추적 이동
- 돌진 전 경로 표시, 방향 고정, 탑승 파도 동기화, 종료 후 즉시 추적
- 카메라 이동 시 전체 정령의 화면 내부 제한과 돌진 취소
- 리스폰 시 탑승 파도·충돌 종료와 추적 재개
- 기존 정령 애니메이션·파도 발사 및 파도 물리 회귀 검사 6개

결과: UnityResults.xml. 실행 로그: unity.log. 01~04 PNG는 추적·예고·탑승 돌진·화면 경계 장면이다.

본편 game 씬의 난이도 및 플레이어와 카메라 참조 연결 상태는 이 격리 테스트의 대상이 아니다.
