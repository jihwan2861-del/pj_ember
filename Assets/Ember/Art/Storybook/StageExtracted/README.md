## 사용 참고

- 구름·가시는 모음 이미지입니다. Unity Sprite Editor에서 각각 분할해 사용합니다.
- 불과 로프는 합쳐진 하나의 정적인 이미지입니다. 로프 스윙·불 애니메이션 구현이 필요한 경우 추가 분할과 애니메이션 제작이 필요합니다.
- 바위 지형은 전체 레이아웃 한 장입니다. 자동 연결 타일셋·RuleTile·충돌체를 만든 상태가 아닙니다. 중앙 기둥 윗부분 등 일부 뾰족한 실루엣이 남아 있어 최종 타일 제작 시 정리가 필요합니다.
- 이미지마다 캔버스 크기와 대상 크기가 다르므로 Unity 배치 시 크기·피벗을 맞춥니다.
- 캐릭터는 한 포즈입니다. 기존 캐릭터 애니메이션을 대체하는 완성 애니메이션 시트가 아닙니다.
- 콜라이더·기믹·씬 연결은 이 이미지 분리 작업에 포함하지 않았습니다.

제작 프롬프트는 PROMPTS.md에 보관합니다.
